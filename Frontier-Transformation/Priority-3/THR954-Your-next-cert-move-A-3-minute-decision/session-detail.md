# THR954 Your next cert move: A 3-minute decision

## 1. はじめに

このセッションは、Microsoft の認定制度（クレデンシャル）を担当する Liberty Munson 氏が、「次にどの認定を取るべきか」を 3 分で決めるための考え方を説明する約 25 分の発表です。質疑応答の時間も長く取られています。

Microsoft の認定には、現在 3 種類あります。ラボで特定のタスクを実行する **Applied Skills**、役割ベースの試験で幅広い専門性を示す **Certifications**、そして日々の仕事の中で積み上がるスキルを認める新しい **Microsoft Pro badge** です。Munson 氏は、この 3 つは競合せず、「**私はこの課題を解ける（Certifications）／実際にやれる（Applied Skills）／毎日やっている（Pro badge）**」という 3 つの異なる主張を補い合うものだと説明します。そのうえで、「1 つのタスクを素早く証明したいなら Applied Skills、職務全体の準備ができていることを示すなら Certifications、毎日使っているスキルの評価を得たいなら Pro badge」という判断基準を示します。

このセッションでは、画面を使ったデモは行われていません。

セッション URL: [https://ignite.microsoft.com/en-US/sessions/THR954](https://ignite.microsoft.com/en-US/sessions/THR954)

## 3. 何に関する発表か

テーマは、AI によって仕事が急速に変わるなかで、「スキルがあること」をどう証明し、どの認定から始めるかです。発表の流れは次のとおりです。

1. 認定がこれまで以上に重要になっている理由（AI による仕事の変化）
2. Microsoft の認定の枠組み（スキルを築く・検証する・成果につなげる、という 3 つの観点）
3. Applied Skills、Certifications、Microsoft Pro badge の紹介と比較
4. 3 分で決めるためのロードマップと、よくある誤解（3 つ）
5. 認定の更新（リニューアル）の仕組み
6. 「3 分の判断チェックリスト」と行動の呼びかけ
7. 質疑応答

Munson 氏は冒頭で、聞き終えたときに分かってほしいこととして、(1) 認定がこれまで以上に重要で、それが皆さんにとって良い知らせであること、(2) 認定のエコシステム（Applied Skills、Certifications、Microsoft Pro badge がどう組み合わさるか）、(3) 最初の一歩を決めるためのロードマップ（3 分未満で決められる簡単なフレームワーク）、の 3 点を挙げています。

## 5. 発表内容の詳細

### 5.1 なぜ今、認定がより重要になるのか

Munson 氏は、背景として AI を挙げています。AI は過去のどの技術の転換よりも速く仕事を変えており、役割の再編はテクノロジー職だけでなく全員に影響します。研究として、**2030 年までに、仕事で使われるスキルの 70% が変わる**という数字を紹介しています。「少し見た目が変わる」のではなく、根本的に変わる、という強調です。

また、反復的な作業を AI に任せ、創造性、洞察、戦略的思考、他者との協働に時間を使う従業員が増えていると述べます。スキル習得を戦略的な優先事項として扱う組織は、実験から実際の事業効果へ速く移行できる、というのが、一貫して見られる傾向だとのことです。適切なスキルがあると、AI の採用が自然に進み、人々が実際の課題に AI を適用し、業務の流れの中で意思決定が良くなる、という説明です。

ここで問いが生まれます。「その人が主張どおりのスキルを持っていることを、どう確かめるのか」。AI を理解していると言うだけでは足りず、採用担当者やリーダーは、本人が実際に何をできるかについての明確で信頼できるシグナルを求めている。それが認定の役割だと説明しています。Microsoft が最近行った調査では、履歴書や面接で主張されるスキルを確かめるために、認定が将来さらに重要になると雇用主が答えている、とのことです（調査の詳細な数値は発表では語られていません）。

### 5.2 Microsoft の認定を考える 3 つの観点

Munson 氏は、認定を次の 3 つの観点で整理しています。

| 観点 | 内容 |
| --- | --- |
| スキルを築く（building skills） | 概念を学ぶだけでなく、実際の仕事で使える、職務に即した能力を身につけること |
| 検証する（validation） | 認定が、Microsoft が裏付ける信頼できるシグナルとして、スキルが本物で信頼でき、自己申告ではないことを示すこと |
| 成果につなげる（impact） | 個人が評価され、組織が自分たちの中でどこに能力があり、どこにギャップがあるかを把握できること |

そのうえで、認定は一度きりのイベントではなく、キャリアの各段階（始めたばかりの人から、職務で専門性を深める人まで）での成長を支える枠組みだと述べています。

### 5.3 3 種類の認定

認定の範囲は、最近 Certifications だけから広げられ、3 種類になりました。

**Certifications（認定資格）**

- 職務で行う主要なタスクを反映した試験に合格して取得する。包括的で、役割ベースの専門性を示す。
- fundamentals（基礎）から associate、expert へと成長を支える段階がある。
- 更新でき、更新は無料。

**Applied Skills**

- 特定の実際のタスクを実行できることを証明するもの。ラボ（実習環境）で、与えられたタスクを実際に行い、採点されて合格すると取得できる。
- ラボは約 25 分で終わる。柔軟で短く、スキル特化で、オンデマンド。事前の登録やスケジュールは不要で、受ける準備ができたらラボを起動してタスクを実行する。
- Certifications に沿っており、beginner（初級）と intermediate（中級）のレベルがある。
- Certifications とともに、LinkedIn などの SNS で共有できる。

2 つは形式は違っても目的は同じで、「実際に何ができるか」を示す信頼できるシグナルを提供する、と Munson 氏は述べています。

**Microsoft Pro badge**

- 数週間前（「先週か、数週間前」という言い方）に発表された、認定ファミリーの最新メンバー。「日々の仕事の流れの中で、スキルを毎日築いている」ことを認めるもの。
- これまで、日々の仕事で Microsoft の技術を使って問題を解くうちに上達しても、その進歩は「認定を取る瞬間と瞬間のあいだ」に起きるため、認められてこなかった。これを変えるために、スキルを継続的かつ本物の形で使うことを認識する、初の種類の認定として導入した。
- Applied Skills や Certifications を置き換えるものではなく、**認定の合間に積み上がる習熟度を捉えて補完する**。

### 5.4 Pro badge の仕組み

前日のセッションで Pro badge の詳細な解説があったため、ここでは概要に留めるとして、次のように説明しています。

1. **オプトイン方式**。デフォルトでは非公開で安全であり、参加するかどうかは本人が選ぶ。
2. オプトインして "calculate proficiency"（習熟度を計算する）ボタンをクリックすると、一定期間のルックバック（遡り）期間で、その技術で何をしたかを見て、習熟度を推定する。ほぼ即座に習熟度のレベルが得られる。
3. 習熟度は、直近のルックバック期間の、技術の使い方に基づく。使い続けるにつれて、**日ごとに変わりうる**。一貫して使っていれば同じレベルに留まることが多いが、上がることも下がることもある。リアルタイムの反映であることが利点だと説明されています。
4. 本人が所有するもので、**レベルを知っているのは本人だけ**。共有したい相手にだけ見せられる。雇用主もアクセスできない。
5. 習熟度は 5 段階。**proficient、advanced、expert** のいずれかになると Microsoft Pro badge（クレデンシャル）を取得できる。レベルは常に更新されるため、現在のスキルを正確に反映し続ける。

最初の Pro badge は **GitHub Copilot** です。Munson 氏は、GitHub Copilot を使っている人にはすぐにオプトインして自分のレベルを確かめるよう勧め、会場の隅にいる GitHub の担当者が、オプトインの手順を手伝ってくれると案内しています。

### 5.5 3 つの認定が語ること

Munson 氏は、3 つを、自分についての 3 つの異なる言明として整理しています。

| 認定 | 言明 | 説明 |
| --- | --- | --- |
| Certifications | 「私はそれを解決できる（I can solve it）」 | Microsoft の認定試験のすべての問題は、達成すべき目標を示したうえで「何をすべきか」を尋ねる、課題解決の形式になっている。知識を問う試験と見られがちだが、問題の設計上そうではない、と述べています。 |
| Applied Skills | 「私はそれをやれる（I can do it）」 | 構造化された評価環境で、タスクを完了できることを示す。 |
| Pro badge | 「私は毎日やっている（I do it every day）」 | 日々の仕事と製品の中で示される習熟度。 |

3 つは矛盾せず、互いを補い合い、1 つだけよりも充実したストーリーを伝えます。

### 5.6 3 分で決めるロードマップ

Munson 氏は、「正解は無く、今の自分に合った出発点がある」としたうえで、次の 2 つの道筋を示しています。

**役割や技術に新しく取り組む人**

1. まず Applied Skills で、1 つのタスクをうまくできることを証明する。
2. 次に fundamentals の認定資格で、幅広い基礎を築く。
3. 役割ベースの associate 認定資格で検証する。
4. Pro badge で、毎日使うスキルの評価を得る。
5. 最後に、expert または specialty の認定資格で、高度な専門性を証明する。

**すでに働いている人**

- **Pro badge から始める**。すでに習熟度を示しているので、それが認められるべきだからです。
- ただし現時点で Pro badge は 1 つ（GitHub Copilot）しかありません。自分向けの Pro badge が無い場合は、いま担当している職務の associate 認定資格でスキルを検証し、その後に expert または specialty で高度な専門性を証明します。
- その場合、Applied Skills を使って、新しく出てくる課題を解決するスキルがあることと、学び続ける姿勢を示してもよい、と説明しています。
- どちらの道でも、旅の途中で Applied Skills を使って特定のスキルを検証できます（スライドで、その間に置かれた小さな黒いひし形が、それを表しているそうです）。

### 5.7 よくある 3 つの誤解

| 誤解 | 実際 |
| --- | --- |
| 認定の種類は 1 つ選ばなければならない | 補完関係にあり、多くの人は時間とともに複数が必要になる。どれが合うかは、キャリアのどこにいるかによる。 |
| Applied Skills と Certifications は同じものをテストしている | 違う。Applied Skills は、ハンズオンのラボで、特定の問題を解決できることを証明する。Certifications は、職務全体の専門性を証明する。 |
| Pro badge は Certifications に取って代わる | 取って代わらない。Pro badge は補完するもの。両者を組み合わせれば、持っているスキルをより正確に表せる。Pro badge は日々の成長を捉え、Certifications は、その成長が環境に合わせて、解くべき問題を解けるように適用できることを示す。 |

Munson 氏は、Pro badge についての情報が広まるにつれて、3 つ目の誤解を耳にし始めたと述べ、「組み合わせて、そのときに最も意味のあるものを選べばよい」と締めくくっています。

### 5.8 認定の更新（リニューアル）

資格を取って終わりではなく、最新に保つ必要があります。役割ベースの認定資格は、**associate、expert、specialty が毎年期限切れ**になります。技術の変化が速く、最新の状態を保ってもらうためだと説明されます。MCT（Microsoft Certified Trainer）の中に 10 個の認定を持っている人がいるという話にも触れ、負担が大きいことを認めたうえで、更新をできるだけ簡単にしたと述べています。

- 更新用の評価（cert renewal assessment）は**無料**で、必要なだけ何度でも受けられる。
- 通常 **約 25 問**で、前回の取得以降の 1 年間に、製品と職務がどう変わったかだけに焦点を当てる。
- 短い**オープンブック**形式で、最新の状態を保っていることを示すためのもの。

更新の話の冒頭で、「認定と Pro badge の更新を忘れないで」と述べています。ただし Pro badge の更新の仕組みは、発表では詳しく語られていません（レベルは常に更新される、という説明のみです）。

### 5.9 3 分の判断チェックリストと行動の呼びかけ

実践的な 5 つの質問が示されました。

1. 今、何を証明する必要があるか。
2. それは 1 つのタスクか、職務全体で通用する幅広い専門性か。
3. それを示す必要があるまでに、時間はどのくらいあるか。
4. すでに毎日使っているスキルの評価を得たいか。
5. 何がキャリアを最も速く前に進めるか。

答えの対応は次のとおりです。

| 答え | 選ぶもの |
| --- | --- |
| 1 つのタスクで、速くハンズオン | Applied Skills |
| 職務全体にわたる幅広い専門性 | Certifications |
| 毎日使っているスキルの評価 | Pro badge |
| キャリアの成長に合わせてポートフォリオを完成させたい | 3 つすべて |

「何も覚えて帰らなくても、これだけは」として、判断を 3 つの問いに絞っています。「1 つのスキルを速く証明したいか → Applied Skills」「職務全体の準備を証明したいか → Certifications」「毎日使うスキルの評価が欲しいか → Pro badge」。

行動の呼びかけは、**Ignite の会場で無料で受けられる認定試験**を、この 3 分ルールで選んで受けることです。会場への問いかけ（Microsoft の認定や Applied Skills を持っている人、Ignite の無料の認定試験をすでに受けた人は）には、挙手がありました。

発表の最後には、AI Skills Navigator へつながるスライドが示されました。認定の情報や受験準備の資料を探す入口だと説明されています。Ignite でまだ試験を受けていない人は、どれか 1 つ予約すること、どの認定にするか分からなければ Munson 氏に声をかけること、が最後の呼びかけです。

### 5.10 質疑応答

会場からの質問と、Munson 氏の回答の要点は次のとおりです。

**次の Pro badge は何か**

いくつか検討中です。次も GitHub のものになる可能性が最も高そうだとしつつ、セキュリティ、Microsoft 365、Copilot の担当者とも話しており、Fabric からも少し関心が寄せられているとのことです。最初に名乗りを上げた領域が先になる、という言い方でした。

**パートナーにとってのメリット（パートナー・コンピテンシー）**

Pro badge は新しいため、現時点ではパートナー・コンピテンシーの対象になっていません。パートナー担当のグループと、何が妥当でどう実現するかを話し合う予定です。ただし重要な点として、Pro badge は本人だけに非公開で、誰に共有するかは本人が選べるように設計しており、「共有が必須」という印象を作りたくない、と述べています。

**セキュリティとテレメトリ**

Pro badge は、実際に何をしているかだけを見る設計です。**コードも、プロンプトの中身も、セキュリティリスクや知的財産と見なされうるものも見ません**。見るのは、製品の使い方（例えば、GitHub の Actions をいくつ設定したか、など）と、さまざまな種類の活動を組み合わせて行うことが、より高い習熟度を示す、という点だと説明しています。プロンプトの数に触れる発言がありますが、「数えているが、数を見ていない」という趣旨に聞こえ、音声が不明瞭なため意味を確定できません。

**企業が管理するアカウント**

現時点では、enterprise managed accounts（企業管理アカウント）は対象外です。近いうちに使えるようにしたいと期待している、とのことです。

**更新が無料なら、不合格の場合は**

「ずっと無料か」という趣旨に対して、「Microsoft が考えを変えるまでは」と答えています。更新の評価を何度でも受けられることは、5.8 のとおり別の箇所で説明されています。不合格になった場合の扱いについての直接の回答は、トランスクリプトからは確認できません。

**Ignite で受けられる無料の認定試験は、更新に使えるか**

更新の評価はもともと無料なので、それに使う必要はありません。Applied Skills も無料だと説明したうえで、「無駄にしないで」と冗談めかして述べています（Applied Skills が無料である点は、聞き取れた限りの内容です）。

**複数のテナントで、多くの顧客のために働く人の Pro badge**

現時点では解決策がありません。話題には出ていて、検討中の課題だと答えています。

**Pro badge の取得要件と、組織向けのレポート**

質問の前半は音声から聞き取れません。回答では、Pro badge の取得は、proficient、advanced、expert のいずれかに達していることが要件で、取得すると本人の transcript に追加され、そこから共有できる、と説明しています。組織向けのレポートについてはまだ検討中で、もし何かを行う場合でも、**個人単位ではなく集計単位**になる、と述べています。個人が共有する内容は、本人が選びます。

**Ignite の無料の認定試験の場所と、fundamentals も含まれるか**

Munson 氏は後ろにあるスキルズ・ハブにいて、どの認定を受けるか迷う人を手伝うと案内します。すでに決めている場合は、次の手順です。

1. 試験の詳細ページ（exam details page）に進み、スケジュールの項目までスクロールして「今すぐ予約」に進む。
2. 受験方法として、テストセンターでの受験を選ぶ。
3. 場所の入力欄に San Francisco と入れると、最初の候補が Microsoft Ignite になる。
4. その後、会場の認定試験のスペース（廊下の突き当たりにあると案内されています）の空き状況が表示される。

枠は急速に埋まっているので、受けたい認定が決まっているなら早く予約することを勧めています。金曜日の 11 時 30 分ごろ（「11:30 か、そのあたり」という言い方で、確定した時刻ではありません）まで枠があるとのことです。質問に含まれていた fundamentals が対象かどうかについて、はっきりした回答は、トランスクリプトからは確認できません。

**古い MCSE が意味を失ったように感じる**

技術ベースの認定は、技術が非推奨になると、スキルを示すという意欲の証明には価値があっても、その特定のスキルセットは組織にとってあまり役立たなくなる、と答えています。そこで 2018 年以降、職務ベースの認定を、基盤の技術から少し独立したものにしてきました。例えば Azure administrator の認定を 2018 年に取り、更新を続けていれば、職務に関わる変化に合わせて最新に保たれているため、雇用主は今も価値があると見なすそうです。

AI のポートフォリオは今年「blew up（大きく作り直した）」と述べ、不満を持つ人がいるのも当然だと認めたうえで、AI の進化が速く、従来の職務の定義は AI で役割が再編された世界では意味をなさなくなったため、と説明しています（発言はここで終わっています）。

## 6. デモ・手順

このセッションでは、画面を使ったデモは行われていません（スライドと口頭の説明が中心です）。Pro badge で「ボタンをクリックすると習熟度が計算される」という説明はありましたが、実演ではありません。Ignite の無料試験を予約する手順は、5.10 の質疑応答の中で口頭で説明されたものです。

## 7. 注意点・発表者の気付き

- **Pro badge は現在 1 つだけです。** 最初の対象は GitHub Copilot で、ほかの製品向けは未定です。
- **Pro badge は Certifications の代わりになりません。** 補完するものです。
- **associate、expert、specialty の認定は毎年更新が必要です。** 更新は無料で、約 25 問のオープンブック形式です。
- **Pro badge には現時点の制約があります。** 企業管理アカウントは対象外、複数テナントで働く人向けの解決策は未提供、パートナー・コンピテンシーには含まれていません。組織向けレポートは検討中で、実施する場合も集計単位です。
- Pro badge は、コードやプロンプトの内容は見ず、活動の種類と組み合わせから習熟度を推定する設計です。
- 技術ベースの認定は、その技術が非推奨になると価値が下がります。そのため職務ベースにして更新を続ける設計にしているが、AI の領域は変化が速いので、今年ポートフォリオを作り直した、という説明でした。

## 8. 利用者にとっての利点

発表で語られた利点は次のとおりです。

- **個人**：認定は、可視性と機会を生み出す。Pro badge は、これまで認められなかった日々のスキル向上を評価に結び付ける。
- **組織**：チームが本当に準備できていることを確認できる。個人の認定は、組織が能力がどこにあり、どこにギャップがあるかを把握する助けになる。
- **スキル習得に力を入れる組織**：実験から実際の事業効果への移行が速い、と述べられています（具体的な数値は語られていません）。
- **更新の負担が小さい**：更新は無料で、約 25 問のオープンブック評価。
- **Applied Skills**：事前の登録なしで、必要なときにオンデマンドで受けられる。

## 9. まとめ

AI により、仕事で使われるスキルの 70% が 2030 年までに変わるという見通しのもと、スキルを証明する手段として Microsoft の認定の重要性が増しています。認定は、役割ベースの専門性を示す Certifications（「解決できる」）、特定タスクの実行を示す Applied Skills（「やれる」）、日々の習熟度を認める Pro badge（「毎日やっている」）の 3 つで、互いを補い合います。

選び方は、新しく始める人は Applied Skills から、すでに働いている人は Pro badge（現在は GitHub Copilot のみ）から、というのが基本です。Pro badge が無い場合は associate 認定資格から進めます。更新は毎年で、無料の短い評価です。Munson 氏は、Ignite で受けられる無料の認定試験をこの 3 分の考え方で選んで受けることを、呼びかけとして示しました。
