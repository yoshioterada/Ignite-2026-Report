## 5. 発表内容の詳細

### 5.1 調査の概要

Liberty 氏は、Microsoft 認定トレーナー（MCT）が学習者にどう準備を指導しているかを知るため、MCT の地域リーダーに調査を送りました。36 人が回答しています。知りたかったのは、学習者が準備できたことをどう判断するか、そして認定試験と Applied Skills の準備でどんなコツを伝えているか、です。

### 5.2 調査結果

**準備の方法**：認定試験では、スキル測定（出題範囲）の確認と学習モジュールの完了が最も多く挙がりました。そこで目立ったのが、スキルを築き、実際に手を動かして経験を積むことです。Liberty 氏によると、アソシエイト、エキスパート、スペシャリティの試験はすべて、問題の作り方の都合で、その技術の実務経験を必要とします。試験の各問題は解くべき問題であり、学習だけでは準備になりません。実務経験は、最も重要な点だと考えている、と述べています。

一方、Applied Skills（ラボで課題を完了する形式）で、学習者が実際に手を動かしていると答えた MCT は 44% にとどまりました。Applied Skills の取得には手を動かす経験が必須なので、これは大きなずれだ、と指摘しています。

**最も重要な活動**：MCT に最重要の活動を 1 つ選んでもらうと、認定試験では AI Skills Navigator の活用、Applied Skills では解決策の構築とテストが挙がりました。ただし、前のスライドの実態では、学習者はそのように準備していません。ここにもずれがあります。

**準備期間**：認定試験の準備は、数週間から数か月前に始めるのが一般的です。これに対して Applied Skills は、28% の受験者が 1 週間未満、89% が 1 か月未満の準備です。手を動かす学習が最も必要な Applied Skills に、最も短い準備期間しか充てられていないことになります。要点は、Applied Skills には余裕を持った準備期間と実践練習を、ということです。

**難しさ**：MCT は、自分たちの準備支援には高い自信を持っています。しかし最も難しいこととして挙げたのは、技術の変化の速さに追いつくことと、十分な時間を確保することでした。

Liberty 氏は、スキル測定は頻繁に更新されると注意しています。Microsoft の認定試験と Applied Skills はすべて **3 か月ごとに見直されます**。そのため、試験の詳細ページと Applied Skills のページを常に確認し、何が測定されるかを把握しておく必要があります。

### 5.3 学習者がよくする 4 つの間違い

自由記述の回答から、同じパターンが繰り返し見つかりました。

1. **暗記に頼る**：試験や Applied Skills は知識を問うものではありません（Fundamentals（基礎）の試験は除く、と補足されています）。大半は実務経験が必要で、暗記ではなく理解が重要です。
2. **手を動かす練習を飛ばす**
3. **不合格をそこで終わりと考える**：失敗は障害ではなく学習の機会で、自分の強みと弱みを見極め、準備の仕方を変えて再挑戦するべきです。準備を何も変えなければ合格は期待できない、と Liberty 氏は述べています。
4. **急いで受ける**：Ignite では試験が無料のため急いで受ける人も多いだろうと理解を示しつつ、こうしたイベント以外では、自分に合った準備のモデルに時間をかけるよう促しています。

### 5.4 準備で実際に効果があること

- 実習ラボと、スキル測定を文字どおりのチェックリストとして使うこと。試験の詳細ページで一つ一つのスキルについて「そのタスクができるか」を正直に確認し、できなければ練習する
- 実習できる環境がなければ、そのタスクを実際に行っている人に、やり方や犯しがちな間違いを聞く
- 試験日を予約する（Applied Skills は予約制ではないため当てはまらない）。期限が準備の動機になる
- MCT が準備完了を判断する最良の目印は、直感ではなく、概念を自分の言葉で説明できること、ラボを成功させられること、自力でトラブルシューティングできること

Liberty 氏の調査に基づく助言は、スキル測定を暗記せず理解すること、本番のつもりで練習すること（ラボ、サンドボックス、あえて壊して直す）、そして期限を決めて計画することです。

### 5.5 Mark 氏の 5 ステップ

Mark 氏は、調査結果を、どの試験にも使える繰り返し可能なルーティンにするとして、次の 5 ステップを示しました。

1. **スキル測定**：AI Skills Navigator で受験する試験のページを開き、学習ガイドを選ぶ。試験に出るスキルが、学習領域ごとに配点の割合とともに載っている。これをドキュメントに貼り、チェックリストにする。リストにあるのにできないスキルがあれば、それが次の学習の対象
2. **ガイド付き練習**：AI Skills Navigator と、手順が示されるインストラクター主導のラボ
3. **独立したラボ**：よく忘れられるステップ。手順を全部は教えず、自分で考えて解くチャレンジラボがある。会場の Skills Quest で体験でき、リーダーボードと賞品がある
4. **（飛ばして後で詳述）**
5. **試験本番**：日付をカレンダーに入れる。準備ができたら予約する、では永遠に準備ができないかもしれない

ステップ 3 に続けて、終えたラボの手順を閉じ、目標だけを見ながら自分のサブスクリプションかサンドボックスで作り直す方法が挙げられました。詰まったらラボの手順書ではなくドキュメントを参照します。試験当日も仕事でも、手順を渡してくれる人はいないため、詰まって抜け出すことこそが目的です。

### 5.6 ステップ 4：練習問題の検死

Mark 氏は、ステップ 4 を意図的に飛ばして、ここに時間を使うと述べました。よくある間違いは、練習問題を、暗記すべき答えとして扱うことです。練習用の評価を終えるとスコアが表示され、多くの人はそこで止まりますが、スコアは間違えた数しか示しません。理由や、正解した問題が知識によるものか偶然かは分かりません。練習評価は診断のツールであり、その価値は、各問題が自分の考え方について教えてくれることにあります。

ルールは **「すべての選択肢を説明できるまで、その練習問題は終わらない」** です。スライドの 3 つの問いには、それぞれ役割があります。

1. 正解が知識によるものか、推測ではなかったかの確認。理由を言えなければ偶然かもしれず、本番では当てにできない
2. 検死そのもの。間違いの選択肢を 1 つずつ取り上げ、何が間違いなのかを突き止める。引っかけの選択肢は、たいてい実在する機能を使う場所だけ間違えている。なぜ違うかを説明するには、その機能が何をし、いつ使うかを知っている必要がある
3. 間違いの選択肢が正解になるまで、状況設定を変えてみる。ある機能の終わりと次の機能の始まりが分かる

説明は、声に出すか書くかで行います。「何となくこれは違う」と言っているうちは、まだ終わりではありません。

### 5.7 例題 1：Azure Spot インスタンス（AZ-104）

AZ-104 の練習評価から出された問題です。Mark 氏は読み上げ、会場に答えを声に出さず頭の中で考えてもらいました（約 10 秒）。

> 問題：Azure の仮想マシンをデプロイする予定で、Azure Spot インスタンスの利用を検討している。Azure Spot インスタンスが退去（エビクション）される要因を 2 つ選べ。

正解は B と C です。ただし Mark 氏は、それだけでは Spot の退去要因 2 つ以外に何も学べないと述べ、4 つの選択肢すべてを解説しました。

| 選択肢 | 内容 | 解説 |
| --- | --- | --- |
| A | 平均 CPU 使用率 | Azure の実在する概念で、自動スケールの規則やアラートの基準になる。しかし Spot の退去とは無関係。Azure は VM が忙しいからという理由で回収しない。「概念は正しいが判断が違う」例 |
| B | 容量 | 正解。Spot VM は空き容量で動いており、Azure が必要になったときに容量を取り戻す |
| C | 価格 | 正解。ただし理由は、価格が変動するからではなく、Spot の価格が、自分で設定した上限価格を上回るから |
| D | 時間帯 | 最も好きな引っかけ。需要は 1 日の中で動くので正しく感じられるが、Azure が判断する条件は時計ではない。相関であって原因ではない |

そこで状況設定を変えてみます。「スケールセットでスケールアウトの契機は何か」と問えば、A が正解になります。D も、「平日の朝、営業開始前にスケールセットのインスタンスを追加するには」や「開発用 VM を毎晩シャットダウンしてコストを節約するには」という問いなら正解です。自動スケールには時刻ベースの規則があり、VM には自動シャットダウン設定があるからです。つまり D は、**別の問いに対する正解**であり、良い引っかけの選択肢の多くはそうです。

解答の解説文は B と C が正しい理由を教えてくれますが、A と D の説明は自分の仕事です。Mark 氏の学習ノートでは、この 1 問が次の 4 行になります。

- 自動スケールは退去ではない
- 空き容量は回収されうる
- 上限価格がしきい値になる
- 相関は原因ではない

この 4 つは他の問題にも使い回せるため、答えが B と C だったことを覚えるよりはるかに価値がある、という説明です。

### 5.8 例題 2：データディスクの移動

今回の落とし穴は問題文の言い回しです。

> 問題：Windows Server を実行する Azure VM が 2 台（VM1、VM2）ある。VM1 には、バックアップファイルを保存するデータディスクが 1 つある。このデータディスクを VM1 から VM2 へ、できるだけ早く移したい。最初に何をすべきか。選択肢は、A. VM1 からデータディスクをデタッチする、B. VM1 を再起動する、C. VM1 を停止する、D. VM2 を停止する。

注目する語は「最初に」と「できるだけ早く」の 2 つです。正解は A です。ディスクは VM2 が使う前に VM1 から外れなければならない、という依存関係があり、Azure では実行中の VM からデータディスクをデタッチできます。

- **B（VM1 の再起動）**：ゲスト OS が再起動するだけで、戻ってもディスクは接続されたまま。状態は変わるが構成は変わらない
- **C（VM1 の停止）**：混乱しやすい選択肢。安全に感じるし可能だが、必須ではなく、問題文は「できるだけ早く」と言っている。試験には、機能するが不要な選択肢がよく出る
- **D（VM2 の停止）**：間違ったマシン。障害は VM1 側にあり、VM2 は稼働中でもデータディスクを受け入れられる

問題を変えて、「データディスクではなく OS ディスクを移す」とすると、実行中の VM から OS ディスクを抜くことはできないので、まず VM1 を停止する必要があり、C が正解になります。選択肢は同じで、1 語変えるだけで勝つ答えが変わります。

そこから Mark 氏は、**「最初に何をすべきか」を問う問題の考え方**を 3 つに整理しました。

1. 現在の状態を整理する（ここでは、ディスクは VM1 に接続され、両方の VM が稼働中）
2. 目標との間にある、ブロックしている依存関係を探す（データディスクは同時に 1 台の VM にしか接続されないため、VM1 への接続がブロッカー）
3. ブロッカーを解消せずに状態だけ変える選択肢を除外する（VM1 の再起動、VM1 の停止、VM2 の停止はいずれも電源状態を変えるだけで、ディスクは VM1 に接続されたまま。ブロッカーを取り除くのは A だけ）

選択肢を読む前にこの考え方をしておくと、正解が見つけやすくなります。

### 5.9 追加の 3 つのテクニック

1. **壊して、直す**：動いているラボをあえて壊す。ロール割り当てを外す、ネットワークセキュリティグループの規則を変える、VM を間違ったサブネットに置くなど。10 分離れてから戻り、他人が壊したものとしてトラブルシューティングする。自力のトラブルシューティングは、MCT が挙げた準備完了の目印の 1 つで、すでに動くものでは練習できない
2. **引っかけを反転させる**：CPU の選択肢や OS ディスクの例でやったとおり、どの練習問題でもコストなしでできる。状況設定を書き換えて間違いの選択肢が正解になるなら、2 つの機能の境界を理解している。試験の問題はその境界にある
3. **条件語に丸を付ける**：選択肢を見る前に、ルールを決める語を探す。「最初に」「最も良い」「管理の手間が最小」「コストを最小化」「できるだけ早く」など。ディスクの問題では VM1 の停止でも目的は達成できるが、条件語によって間違いになった

Mark 氏は、問題文に明記されていなくても、**「管理の手間が最小」は常に前提と考えるべき**だと述べています。正解が 2 つ並ぶとき、片方は明らかに実行が簡単で、それは怠慢ではなく効率だからです。

### 5.10 間違えた問題を学習計画にする 4 ステップ

各ステップは 1〜2 分です。

1. **検死**：なぜ自分の答えが負けたかを問う。機能を知らなかったのか、条件語を読み違えたのか、別の機能に属する選択肢に惑わされたのか
2. **一般化**：「文字ではなく規則を書く」。「問題 16、答え A」というメモは、本番で問題 16 には出会わないので役に立たない。「データディスクは実行中の VM からデタッチできるが、OS ディスクはできない」という規則は、まだ見ていない問題にも答えられる
3. **検証**：自分の規則をまだ信用せず、AI Skills Navigator で前提条件と例外を確認する
4. **実行**：ラボで構築し、壊して、直す。同じ目標の別の問題で、規則が成り立つか確かめる（証明のステップ）

まとめて「説明する、作る、直す、証明する」です。これは、調査で MCT が語った準備完了の確認方法と同じだと述べています。

### 5.11 持ち帰りと宿題、AI Skills Navigator

Mark 氏は 3 つの持ち帰りと、宿題を示しました。

1. 練習問題のゴールが変わった。正しい文字を選ぶことではなく、**すべての選択肢を他の人に説明できる**こと。MCT が準備完了と判断する最大の目印が、概念を自分の言葉で説明できることだという Liberty 氏のデータとも一致する
2. 選択肢を見る前に条件語を見つける。数秒で済み、ディスクの問題を決めたのはそれだった
3. 間違いは失敗ではなく、次に学ぶことの指針。規則に直し、さらにラボにすれば、そうなる

宿題は、Ignite を出る前に、次に受ける試験の練習評価を開いて 5 問解き、その 5 問をすべて検死することです。選択肢 20 個を説明することになります。50 問の模擬試験を解くより時間はかかりますが、学べることは多いという説明です。練習問題を暗記するのではなく、理解の穴を見つけるために使います。

最後の資料として、AI Skills Navigator が紹介されました。AI でロールに合わせた学習パスを作り、スキル習得のコンテンツと資格を 1 か所にまとめます。検死で穴が見つかったら、検索結果を探し回らずに、そこに持ち込んで次の行動を知る、という使い方です。QR コードか、aiskillsnavigator.microsoft.com から利用できます。

### 5.12 質疑応答と補足

質疑の時間は約 3 分とされましたが、会場から質問は出ませんでした（発話では質問は確認できません）。その代わり、Liberty 氏は、心理測定の視点と 20 年の経験から、次のコツを補足しています。

- **試験は受験者を引っかけようとしていない**。問題が引っかけだと感じたら、考えすぎている。条件語を探すと正解が見つかる

セッション後は、Community Cafe（発話では Learning Lounge とも言い直されています）で質問を受けると案内されました。学習面に詳しい MCT と、評価面に詳しい Liberty 氏の両方に話を聞けるとのことです。アンケートへの回答も呼びかけられました。

## 7. 注意点・発表者の気付き

- 認定試験の問題は、解くべき問題で構成されている。学習だけでは準備にならず、実務経験が必要（Fundamentals は除く）
- Applied Skills は、手を動かす経験が必須なのに、準備期間が最も短い傾向がある
- 試験と Applied Skills は 3 か月ごとに見直されるため、スキル測定を定期的に確認する
- 不合格のあとに準備を変えなければ、合格は期待できない
- 練習問題の答えの文字を覚えても役に立たない。原則を記録する
- 「管理の手間が最小」は、明記がなくても常に前提と考える
- 引っかけの選択肢は、別の問いでは正解になる、実在する機能であることが多い

## 8. 利用者にとっての利点

学習者（受験者）にとっての利点として語られたのは次のとおりです。

- 調査結果に基づいた、準備の優先順位（スキル測定の確認、手を動かす練習、十分な準備期間）が分かる
- AI Skills Navigator で試験のスキル測定（学習領域ごとの配点つき）を確認し、学習ガイドをチェックリストにできる
- 会場の Skills Quest で、リーダーボードと賞品付きのチャレンジラボを体験できる
- 検死、反転、条件語の確認、規則化といった、練習問題から多くを学ぶ具体的な技術が得られる

## 9. まとめ

MCT 地域リーダーの調査（36 人）から、準備で効果があるのは、スキル測定の理解、手を動かす練習、余裕のある計画だと示されました。一方で、Applied Skills への準備は、手を動かす経験が必須なのに実践する人が 44% にとどまり、準備期間も短いというずれがあります。
