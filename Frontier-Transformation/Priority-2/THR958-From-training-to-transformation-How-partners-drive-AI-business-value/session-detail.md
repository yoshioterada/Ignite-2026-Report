## 5. 発表内容の詳細

### 5.1 Frontier Transformation の 4 つの柱

Frontier Transformation は、組織が AI への意欲を測定可能な事業成果に変えることだと説明されました。成功の指標は次の 4 つの柱で整理されます。

| 柱 | 説明 |
| --- | --- |
| 従業員体験を豊かにする | 日常業務をより価値の高い仕事に変える。そのために、ツールを使いこなすスキルを身に付け、自信を持てるようにする |
| 顧客との関わりを作り直す | スキルを持つチームが AI を使って、より速く応答し、よりパーソナライズする |
| 業務プロセスを再構築する | エージェントと自動化により、業務をエンドツーエンドで変える。日々の作業の中でプロンプトを使う段階を超えて、働き方そのものを作り直す。スキリングなしには実現しない |
| イノベーションの伸びを押し上げる | AI に慣れたチームは実験を重ね、事業に多くの案を持ち込む。そこで ROI（投資対効果）などの成果が見えてくる |

### 5.2 トレーニングパートナーの役割

Microsoft 側は、パートナーが貢献する要素を次のように整理しています。

- **自社の変革から始める。** Accenture には数十万人の従業員がおり、まず自社が Customer 0 になりました。自社の事業を作るうえで Copilot とエージェントを使い、その経験をほかの企業への助言に生かしています。
- **旅路のあらゆる段階にスキルを提供する。** あらゆる役割、リーダー、ユースケース発想を対象とし、セキュリティやデータなど事業のあらゆる領域を含みます。強度の高いハンズオンラボで、組織全体の基礎レベルの習得から、特定チームの実践までに対応します。
- **幅広いトレーニングサービス。** エンドツーエンドの研修ソリューション、複数の学習形態（セルフペースのオンライン、ワークショップ、ハンズオンラボなど）があります。認可を受けた Microsoft パートナーは、Microsoft 認定トレーナーを使います。
- **スケールと現地性。** 各国のパートナーが現地の言語で、顧客の事業と課題を理解したうえで支援します。
- **認定資格と人材開発。** 技術チームだけでなく、ビジネスユーザー向けの資格も用意されていると説明されています。人材開発を手がけるパートナーも多くあります。

トレーニングパートナーは Microsoft の MAICPP プログラムに属しており、画面下部のリンクから情報確認やパートナー検索ができます。

### 5.3 AI 変革の 3 段階と、停滞する理由

Alan 氏は、成功する AI プログラムは次の 3 段階を踏むと述べています。

1. **学ぶ。** AI と Copilot が何であり、自分の職務で何を意味するかを理解する。
2. **適用する。** 実際の仕事で、プロンプト、ワークフロー、ソリューションを作る。
3. **成果を出す。** 利用が増え、時間が節約され、個人が日常の中で実感し、事業が出力と結果で確認できる。

プログラムが止まるのは、学習が 2 と 3 の段階に進まないときです。コースを修了し、認定資格に合格し、全員を研修したと社内で確認しても、月曜の朝の行動は変わらないままになります。

### 5.4 Accenture Learn Vantage の紹介

Learn Vantage は、Accenture の AI と Microsoft に特化した研修事業です。2026 会計年度だけで 213 万人の Microsoft 学習者を研修しました。Microsoft 最大のグローバル認可トレーニングサービスプロバイダーであり、Microsoft の公式カリキュラムを全て提供する認可を受けていると説明されました。

他社との違いとして、次の 3 点が挙げられました。

| 特徴 | 内容 |
| --- | --- |
| 閉じたループ | Accenture が技術を導入し、Learn Vantage が定着を担う。スキリング、導入、プラットフォームの定着を 1 社が担うため、抜け落ちがない |
| 深さ | Accenture は 10 億ドルを投じ、AI 駆動の研修組織を作った。役割別の Microsoft スキル学習をブレンド形式で提供する。講師主導、バーチャル、セルフペースのデジタル学習のほか、AI による役割別の個別学習パス、アセスメント、ナノ学位、ゲーム化、認定資格、マネージャー向けダッシュボードがあり、業界、職務、組織のガバナンスに合わせてカスタマイズできる。現場で導入を進めている同じ Accenture の専門家が担当する |
| 規模 | 17 万人の認定 Microsoft プロフェッショナルを正社員として擁し、すでに顧客の現場で働いている。複数の拠点と言語で、採用と利用という同じ KPI を軸にした学習プログラムを提供する |

### 5.5 支援の 7 つの形

Alan 氏は、顧客の現在地に合わせる方法を 7 つに整理しました。

1. 人材変革：学習戦略を事業の方向と揃える
2. スキルアセスメント：不足を特定し、習得したスキルを認定する
3. 学習そのもの：AI 対応のプラットフォームで個別の学習パスを提供する
4. デジタルコース：実務に近いハンズオンのプロジェクトを使う
5. アカデミーとブートキャンプ：経営層、技術チーム、一般の従業員向けに専門家が行うプログラム
6. 没入型シミュレーションと AI コーチ：すぐにフィードバックが得られる練習の場
7. プログラム管理：大規模プログラムの運営と、生まれた価値の測定

成果は、アセスメントとパフォーマンスで証明するという考え方です。

### 5.6 プラットフォームと KPI

すべては Azure 上に構築された、AI ネイティブの統合プラットフォームの上にあります。組織ごと、個人ごとにカスタマイズされます。学習者がログインしても汎用のカタログや選択肢の一覧は表示されず、その人の旅路だけが表示されます。役割、習熟度、到達したいスキルを把握し、段階ごと、クエストごと、チャレンジごとの個別の学習パスを出します。デジタル教材、ハンズオンラボ、実世界のシミュレーション、AI コーチング、コミュニティが 1 つの流れになり、コンテンツを消費するだけでなく、実践に向かわせる設計です。

スキルアセスメントで現在地を確認し、キャップストーンプロジェクトで実世界への適用を求めます。各ステップは組織の事業成果の目標に結び付いています。KPI は顧客が事業で追う指標に合わせ、利用率の向上、生産性に達するまでの時間の短縮、T+90（90 日後）での能力の定着などがあります。この説明責任の枠組みは、深い取り組みを設計する段階で一緒に作るとのことです。

### 5.7 事例 1：従業員 4 万人の金融データ企業

グローバルな金融データ企業と、4 万人規模の AI リテラシー（AI を使いこなす力）プログラムを実施しました。社名は明かされていません。組織名を冠して「Sprint AI Academy」と名付け、一部の技術専門家ではなく、全社の能力にすることが目標でした。結果は次のとおりです。

| 指標 | 結果 |
| --- | --- |
| Microsoft Copilot の利用 | 4 倍に増加 |
| 日次アクティブユーザー | 7,200 人から 2 万人超 |
| 研修の修了率 | 100% |
| ネットプロモータースコア | プラス 52 |
| 社内のプロンプトライブラリへの追加 | 8,500 件超のカスタムプロンプト（同社では「スパーク」と呼称） |

Alan 氏は、これらはライセンス数ではなく、毎日使うことを選んだ人の数だと強調しました。従業員が AI を使う側から作る側へ変わり、作ったものを共有し合った点が、学習から応用への移行だと説明しています。Microsoft の営業担当者向けには、スキリングを展開に含めたときの Copilot 定着向上の姿だと述べました。

うまくいった理由は、定着が止まる前の早い段階で関与したことと、成功をどう測るかを経営層と最初に合意したことです。同社の人材育成責任者の言葉として、AI の時代に最大の資産はアルゴリズムではなく、育てる人材だという言葉が紹介されました。このプログラムは、CEO サークル・オブ・エクセレンスと、3 つの Brandon Hall アワードを受賞しています。

### 5.8 事例 2：製薬企業

もう 1 つは、Microsoft の SM&EC セグメントに属する製薬企業（ヘルスサービス企業）です。複数の地域にまたがる規制業界で、事業全体に Power BI の能力が必要でした。

以前は地域ごとに分断された研修を行っていました。Learn Vantage の導入後は、責任を持つ学習パートナー 1 社、標準化されたグローバルモデル 1 つ、一貫した学習経路を得て、組織全体で Microsoft の Pl. 300 認定（音声認識の都合で表記が確定できません）を取得するという目標に取り組みました。12 か月で 600 人超の専門職を研修し、365 日分のデジタルコンテンツ、ラボへのアクセス、学習コミュニティを提供しています。

3 つ目の学習コミュニティが最も重要だと説明されました。コース終了後も学習が続くよう設計され、試験対策や模擬試験を進める動機付けになりました。規制業界のため、プライバシー、ガバナンス、応用シナリオも扱い、日々の実際の働き方に合った内容にしました。

### 5.9 2 事例の共通点と、聴衆への呼びかけ

企業の規模に関係なく、パターンは同じだと述べています。事業の能力から始め、役割に合わせて研修し、結果を測るという流れです。共通点は 3 つです。

1. スキリングを早期に組み込む。AI 展開の初期に設計し、定着が止まって不満が出てからの後付けにしない。
2. 役割に合わせた研修にする。個別の学習パス、ハンズオン、コミュニティを使い、形式的な汎用コースにしない。
3. 変化を測る。KPI を事前に合意し、利用状況、修了、認定資格を前後で追跡する。

そのうえで、3 つの行動が示されました。顧客でも Microsoft の営業担当者でも当てはまります。

1. **ユースケースを 1 つ挙げる。** 顧客は、停滞している Copilot または AI 導入を 1 つ挙げる。営業担当者は、販売したライセンスと有効化・利用の差を見て、差のあるアカウントを 1 つ挙げる。Alan 氏は、複数見つかると述べています。
2. **Microsoft のチームを巻き込む。** Microsoft のアカウントチームに、Copilot と AI 展開のためのスキリングについて尋ねる。
3. **1 つのチームから始める。** 顧客は、スキルのギャップを評価し、KPI に紐づく役割別の学習経路を作る。営業担当者は、次の Copilot 提案にスキリングを加えれば、範囲は共同で作成し、実作業は Accenture が引き受ける。

## 7. 注意点・発表者の気付き

- コースの修了や認定資格の合格を確認しただけでは、行動は変わりません。学習が応用と成果創出の段階に進まないと、プログラムが止まると述べています。
- スキリングは、導入後に定着が止まってから後付けするものではなく、AI 展開の最初から設計するものだと繰り返しました。
- Alan 氏は、人数で測るのではなく、事前に合意した KPI で前後を比較するよう求めています。
- 事例 1 の数値は、事前に成功の測り方を経営層と合意し、早期に関与したことで、前後比較を示せたと説明されています。

## 9. まとめ

Microsoft 側は、Frontier Transformation の 4 つの柱を示し、トレーニングパートナーがスキルを通じて各柱を支えると説明しました。Accenture Learn Vantage の Alan 氏は、AI 変革を「学ぶ、適用する、成果を出す」の 3 段階で捉え、研修の価値は座席数ではなく行動の変化で測るべきだと述べました。
