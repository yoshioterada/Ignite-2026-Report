## 3. 何に関する発表か

背景として、AI への移行が急速に進み、顧客は試行や PoC の段階を過ぎて、数週間で設計と開発を終え、業務の流れの中で早く本番運用したいと考えている、という認識が示されました。この変化を **Frontier 変革** と呼び、ISV に次の 3 点を同時に変えるものだと説明しています。

- 作り方：顧客は「AI を後付けしたもの」ではなく、AI ネイティブのソリューションを求める。
- 売り方：財務部門と調達部門が購入しやすく、クラウドのコミット予算を使える形で販売する。
- 差別化の仕方：最初の商談の前に信頼性が見られ、信頼がこれまで以上に重要になる。

Microsoft の役割は、この 3 点を楽にすることで、その場が「Marketplace」と「パートナープログラム」の 2 つだと整理されています。発表の流れは次のとおりです。

1. 市場の変化と Frontier 変革
2. Marketplace の価値と実績の数値
3. パートナープログラムと Frontier Accelerate for Marketplace の全体像
4. ビルドと公開、成長（Zach）
5. 差別化（Kyle）

### 5.1 Marketplace の価値と実績

Marketplace は、顧客の購入方法とパートナーの販売方法の幅をつなぐ基盤だと説明されました。発見と購入は、Marketplace の中、Microsoft の製品の中、パートナー主導の販売の中で行われます。

| 対象 | 得られるもの |
| --- | --- |
| ソフトウェア会社 | Microsoft 365 Copilot や製品体験の中を含む、顧客への経路が増える。チャネルパートナーを通じた成長の経路も増える |
| チャネルパートナー | 自社の専門性とサービスに、ソフトウェア体験を組み合わせて、顧客に提供できる |
| 顧客 | すでに使い慣れ、信頼している調達手段と、関係のあるパートナーを通じて利用できる |

次の実績が語られています。

- Marketplace 経由の支出は、パートナーと合わせて数十億規模に達している（通貨は発話では確認できません）。
- その支出は前年比で倍増しており、**今年も再び倍増する見込み**。
- 新規顧客の **60%** は米国外。
- 契約済みのクラウド支出（Azure のコミット）がある顧客の **85%** が、Marketplace で取引している（コミットを指す略語は音声認識の都合で表記が確定できません）。パートナーにとっては、数十億規模の事前コミット済み支出が商談を加速する材料になる。
- マルチパーティ プライベートオファーを **39 の市場**に展開済みで、ロードマップにはさらに予定がある。
- チャネル主導の取引は、平均で **80% 大きい**。

### 5.2 パートナープログラムと Frontier Accelerate for Marketplace

パートナープログラムは、特典、インセンティブ、スキル習得、支援を通じて、パートナーの事業を加速する、コインの裏側だと位置づけられています。ISV の道のりは次の 3 段階です。

1. **ビルド（構築と公開）**：Microsoft Cloud 上で構築し、Marketplace に取引可能なソリューションを公開する。AI とエージェントの構築を加速する。
2. **グロー（成長）**：販売に入り、共同販売を始める。Marketplace のフライホイール（好循環）を回し始める段階。
3. **ディファレンシエート（差別化）**：規模を獲得し、顧客と Microsoft の営業担当に対して際立つ。最上位の特典とインセンティブを受ける。

> 補足：旅は直線的ではない、と述べられています。Marketplace で取引中の主力ソリューションを持ちながら、次のソリューションに AI を組み込んでいる、というケースが例に挙がっています。

**Frontier Accelerate for Marketplace** は 9 月末に開始され、Microsoft AI Cloud Partner Program の中で、各段階に合わせた特典を統一された流れで提供するものです。以前は、様々な施策や特典が個別に存在し、効果はあっても「あちこちに散らばっていた」ため、合理化した、と説明されています。

選択肢は次の 2 つです。

| コース | 内容 |
| --- | --- |
| 無料のパス | 実績に応じて得られる報酬プログラムのような仕組み。「やるほど、もらえる」。AI ツールとエージェント、Azure スポンサーシップ、共同販売、認定（Designation）などを獲得し、解放していく |
| Frontier Accelerate for Marketplace Premium（有料） | 人が介在する支援（エンゲージメントマネージャー）、技術コンサルテーション、追加の Azure スポンサーシップ、さらに多くの市場投入の特典 |

運用は Partner Center の 1 か所で行えます。Kyle は、自社で進め方を理解しているなら無料のパス、各段階でより多くの特典と支援が必要なら Premium が適しており、ROI の説明も簡単だと述べています。また、**名称の変更だけではなく、成果が出ている領域に投資を倍増させた**点を強調し、スライドでは緑色の項目が実質的に変更・更新された部分だと説明しました（スライドの内容そのものは音声からは確認できません）。

### 5.3 ビルドと公開（Zach）

無料と Premium のどちらでも支援されます。

- **無料のパス**：AI 主導・支援のツールと、AI の構築と公開のインセンティブが、すぐに利用できる。数か月前までは、差別化の段階にある認定ソフトウェア（Certified Software）の Designation が必要だった、**最大 8 万ドルの現金インセンティブ**が、無料でも対象になりうる。
- **Premium**：エンゲージメントマネージャーが、構築と公開の道のりを最後まで伴走し、AI とアーキテクチャの設計・レビューなど複数回の技術コンサルテーションを受けられる。
- **ROI の例**：Premium の価格は **1,550 ドル**で、すぐに使える **3 万ドルの Azure スポンサーシップ**が付く。

### 5.4 成長（Zach）

無料のパスで、**段階的に Azure スポンサーシップが増え、最大 42 万 5,000 ドル**に達します。内訳は次のとおりです。

- **40 万ドル**は顧客向け。取引を成立させる際に使い、取引先の離脱防止や、Marketplace に初めて移行する顧客への後押しに使われることが多い。
- **2 万 5,000 ドル**は、パートナー自身のテナント向け。Marketplace で無料トライアルを提供した後に、自社の Azure 費用を相殺するために使う。

このほか、共同販売の対象資格が得られます。Premium では、エンゲージメントマネージャーが共同販売の道のりにも伴走し、利用条件の確認、スポンサーシップの受け取り方、次の階層への到達時期などを支援します。さらに、ビルドと公開の段階で Visual Studio や Microsoft 365 のライセンス（SKU）が増え、成長の段階でも市場投入の特典が増える、とのことです。

### 5.5 チャネル（Zach）

「リード（見込み客）はどこか」という質問に対する答えが、チャネルです。ハイパースケーラー各社の Marketplace で、チャネルパートナーが ISV の新市場への進出とサービスの付加を助け、販売力を引き出している、という説明です。

- マルチパーティ プライベートオファーの対象になったチャネルパートナーが、Microsoft の Channel Ready（発話で繰り返された窓口名。URL の綴りは発話では確認できません）で関与すると、すぐに **5,000 ドルの Azure スポンサーシップ**を解放できる。
- 無料のパスで ISV が使える最大 42 万 5,000 ドルに加えて、チャネルパートナーは**最大 20 万ドル**を獲得できる。両方を重ねて使える。
- 2027 年も、チャネルへの投資を拡大し続ける。リセール有効化オファーとマルチパーティ プライベートオファーを、ISV とともに伸ばしていく。
- 今週後半に、このパイプラインを理解できるセッションがあると案内された。

### 5.6 差別化（Kyle）

> 補足：この節の金額（210 万、200 万、10 万、16 万、1 万 2,500）は、通貨が発話では明示されていません。他の節と同様にドル建てで書いていますが、確定ではありません。

差別化は、**少なくとも 1 つのソリューションで認定ソフトウェアの Designation を得る**と解放されます。最上位の特典とインセンティブが対応します。

- **Azure スポンサーシップは最大 210 万ドル**。そのうち約 200 万ドルは顧客側で取引成立のために使い、**最大 10 万ドル**はトライアルや PoC の費用の相殺に使う。この枠は、この新しい施策の開始に合わせて**倍以上に増やした**。
- **パートナーインセンティブ（無料のパスに含まれる）**：顧客の移行とモダナイズなど、推進したプロジェクトに対して現金を提供する。顧客移行・モダナイズのインセンティブ（Customer Migrate and Modernize）も含み、**最大約 16 万ドル**。リード獲得、マーケティング、市場投入の資金にできる。
- **Premium**：ソリューションごとに、3 つから 1 つを選べる強力な市場投入パッケージ。希望小売価格は約 1 万 2,500 ドルで、専用に制作した動画などが含まれる。このほか、リードスコアリングと、RFP に添えられる認定レターがある。

今後の予定として、年内に次の 2 点が提供されると述べられています（提供済みではありません）。

- 認定を取得する資格と更新を、より合理的に行える仕組み。
- Frontier 変革を推進するパートナー向けの、差別化の選択肢とインセンティブの追加。

### 5.7 ゲスト：UiPath の Cesar

Kyle が「UiPath とは広範に協働し、Microsoft との成長を実現した」と紹介し、整理や活用のコツを尋ねました。Cesar は、Microsoft との成長は次の 3 つに支えられていると述べています。

1. **自信を持って作る**：Microsoft の技術チームと並んで共同イノベーションを行う。Microsoft のグローバルなマネージド ISV（聞き取りは音声認識の都合で確定できません）であり、認定ソフトウェアの Designation を取得している。
2. **買いやすくする**：Microsoft Marketplace を使い、顧客のクラウド戦略に合わせる。顧客が Marketplace で購入すると、Microsoft へのコミットを減らせる。ファーストパーティとサードパーティの競合状態をなくした Microsoft の対応を評価している。Marketplace で買いたいという顧客が増えている。
3. **市場投入を揃える**：Marketplace と共同販売を販売方法に組み込み、マルチパーティ プライベートオファーとリセール有効化オファーを使っている。さらに Azure スポンサーシップを特典として追加し、顧客の購買傾向スコアと合わせて、案件をより速く見つけている。

**顧客事例（IDB Bank、商業融資アプリケーション）**：顧客は会場に来ており、今週後半にセッションがあり、Microsoft が成功事例を公開済みと紹介されました（銀行名は音声認識の都合で表記が確定できません）。UiPath と Microsoft の両方の技術でアーキテクチャを作ったことが、顧客にとって重要でした。顧客は Power Automate や Microsoft 365 を使い、基盤を整えており、Power Automate、SharePoint、Copilot Studio、Foundry を使っています。UiPath はそれにオーケストレーションを加え、孤立したプロセスではなくエンドツーエンドで調整されたプロセスにしました。UiPath のエージェントと Microsoft のエージェント、人が介在する工程を調整しています。顧客が共有する期待成果は、**手作業による文書処理の 70% 削減**です。

**新市場へのチャネル展開のコツ**：

- Microsoft が機能を広げる順に、地域ごとにチャネルを拡大する。まず英国、カナダ、米国でマルチパーティ プライベートオファーを始め、Microsoft がヨーロッパ、オーストラリア、日本、南アフリカに広げた際も同じようにした。
- 社内の現場に周知し、パートナーマネージャーが各地のパートナーに働きかけて、利点を伝える。
- Microsoft と共同セッション（「Microsoft、または Marketplace とともに成長する」）を開き、自社のパートナーが特典を受けられるよう支援する。
- 実績として、ここ数年は Marketplace で毎年 3 倍、4 倍で成長してきた。**今年はここまでで 300% 成長**している。要因は、マルチパーティ プライベートオファー、リセール有効化オファーなど、Marketplace の特典全般。

## 8. 利用者にとっての利点

ここでの「お客様」は、ISV と、その顧客およびチャネルパートナーです。

- ISV：窓口が Partner Center に統一され、複数の施策を探し回る必要がなくなる。
- ISV：無料のパスで、AI の構築と公開のインセンティブ（最大 8 万ドル）、Azure スポンサーシップ、共同販売の資格が得られる。
- ISV：Premium では、1,550 ドルで 3 万ドルの Azure スポンサーシップに加え、エンゲージメントマネージャーと技術コンサルテーションが付く。
- 顧客：Marketplace で購入すると、Microsoft へのコミットを減らせる（UiPath の説明）。
- チャネルパートナー：5,000 ドルのスポンサーシップをすぐに受けられ、最大 20 万ドルまで獲得できる。
- 事例：UiPath は、今年ここまでで 300% の Marketplace 成長。IDB Bank の顧客は、手作業による文書処理の 70% 削減を見込む。

## 9. まとめ

- Marketplace の取引額は前年比で倍増し、今年も倍増する見込みで、チャネル主導の取引は平均で 80% 大きい。
- Frontier Accelerate for Marketplace は、散らばっていた特典を、ビルドと公開、成長、差別化の 3 段階にまとめた、Partner Center 上の 1 つの流れである。
- 無料のパスで多くの特典を得られ、人の支援や追加の特典が必要なら Premium を選ぶ。
- ビルドと公開では最大 8 万ドルの現金インセンティブ、成長では最大 42 万 5,000 ドルの Azure スポンサーシップ、差別化では最大 210 万ドルの Azure スポンサーシップと最大約 16 万ドルの現金インセンティブがある。
- チャネルパートナーを巻き込むと、さらに最大 20 万ドルのスポンサーシップが上乗せできる。
- UiPath は、共同イノベーション、Marketplace での購入のしやすさ、市場投入の整合の 3 点で成長を実現している。
