# THR1036 Grow your business with Unified Broker and Unified EA Co-sell

## 1. はじめに

Microsoft のサポートを、普段ライセンスを購入しているパートナー経由で契約したい。こうした要望に応えるのが Unified Broker Program です。この発表では、その仕組みと、顧客のサポート需要を見つける活動を報奨する Unified EA Co-sell の試行を紹介しています。

両者の違いは、請求・契約を仲介する仕組みに加え、営業段階で協業するかどうかです。**販売経路が変わっても、Unified のサポート提供そのものは Microsoft が担います。**

## 3. 何に関する発表か

Unified は、主に大企業顧客向けの Microsoft のプレミアムサポートです。直接 Microsoft から買う方法と、パートナー経由で買う方法を説明しています。

発表の前半は Unified Broker Program の規模、収益化、参加対象です。後半では、現在試行中の Unified EA Co-sell のインセンティブと、CDW による最初の成約事例を取り上げました。

製品障害の解決手順や、サポートのサービス水準を解説する発表ではありません。パートナーが既存の顧客関係に、サポート契約をどう組み込むかが主題です。

## 4. 発表者が伝えたいメッセージ

顧客のライセンス、Azure、デバイスなどを扱うパートナーは、その顧客に必要なサポートも把握しやすい立場です。契約の仲介だけでなく、需要の発見段階から Microsoft と協業する余地があります。

また、パートナーの収益は Microsoft からのインセンティブだけではありません。自社の付加価値サービスや取引手数料を組み合わせられます。ただし、それぞれの条件を混同しないことが大切です。

## 5. 発表内容の詳細

### 5.1 Unified Broker Program の役割分担

直接購入でもパートナー経由でも、サポート提供は 100% Microsoft が担います。パートナーが担当するのは、顧客との契約と請求です。

既存のライセンスや Azure の取引にサポートを組み合わせたり、顧客の希望する請求日程に合わせたりできる点を説明しました。例えば、このサービスでは Microsoft が行わない月次請求について、パートナーが対応する余地があります。

### 5.2 プログラムの成長

開始時の FY22 は、12 の試行国、約 25 パートナー、売上 2,100 万ドルでした。発表時点では、62 市場、250 超のパートナーへ広がっています。

前年の売上は 3 億 4,600 万ドルで、当年は約 4 億ドルを予測し、登壇者自身は 5 億ドルに近づく可能性にも言及しました。また、当該会計年度末には累計売上が 10 億ドルに達する見込みと説明しています。

世界の Unified の取引額のうち、10 ドルに 1 ドルがパートナー経由だという紹介もありました。当年の売上や累計額は、確定実績ではなく予測です。

### 5.3 パートナーの収益と参加対象

収益化は、主に二つの方法です。

| 方法 | 発表された内容 |
|---|---|
| 付加価値サービス | 自社のサービスを加え、顧客との関係を深める |
| 取引手数料 | 一般には 2〜5% 程度。二桁の例もあると紹介 |

手数料は Microsoft が決めるものではなく、パートナーと顧客の間で決めます。全パートナーに同じ率が適用される説明ではありません。

参加対象は、旧 LSP に相当する Scale Solution Provider が事前適格と説明されました。例外もあるため、対象外と思われる場合は担当者へ相談できます。基本の相談先は Partner Development Manager（パートナー担当マネージャー）です。

### 5.4 Broker と Unified EA Co-sell の違い

Broker の仕組みでは、Unified の範囲と価格を Microsoft の営業担当が決め、パートナーは契約と請求を仲介します。このプログラム自体には、営業協業に対するインセンティブはありません。

一方、Unified EA Co-sell では、すでにライセンスや Azure の相談を受けているパートナーが、サポートの必要性を聞き取り、Microsoft へ顧客をつなぎます。その営業活動を報奨する試行です。

| 契約 | 紹介されたインセンティブ |
|---|---|
| 単年契約 | 3% |
| 複数年契約 | 4% |

さらに Broker の付加価値サービスや手数料も組み合わせます。発表では、複数年契約の 4% と取引手数料 5% を合わせ、9% になる例を示しました。

> 注意：9% は説明用の組み合わせです。取引手数料は顧客との合意事項で、Microsoft からの固定報奨率ではありません。

### 5.5 1,000 万ドルの説明例

登壇者は、1,000 万ドルの案件を例に、単年なら 3% で 30 万ドル、複数年なら 4% で 40 万ドルと説明しました。

四年契約の例では、契約が続く間、各契約応当日に 40 万ドルを現金で支払うという紹介です。ただし、年度ごとの算定対象額、契約変更時の扱い、支払条件の細目までは説明されていません。この例だけを、任意の総契約額に当てはめることはできません。

Microsoft の営業側にも利点があります。パートナーとの協業で商談を速く進められれば、自社の売上と営業報酬にもつながります。双方に協業する理由を作る考え方です。

### 5.6 CDW：サポートと付加価値サービスを予算内で組み合わせる

CDW は英国と米国の試行に参加し、発表の年の 5 月に Broker Program へ加入しました。6 月には、世界で最初であり英国でも最初となる案件を成約したと紹介されました。

顧客は匿名です。以前 Unified を使っていたものの、CSP の経路へ移った後に一週間の大きな停止を経験し、サポートを見直していました。Microsoft と CDW が話を聞いた結果、顧客は再び Unified を望んでいることが分かります。

ただし、予算には明確な上限がありました。双方の営業担当が協業し、Unified を基礎に、CDW の付加価値サービスを組み合わせる提案を作りました。顧客は希望するサポートと追加の支援を、限られた予算の中で受けられたという説明です。

> 注意：この事例は、特定の顧客の経験です。CSP 全般のサポート品質や障害対応を比較したものではありません。

### 5.7 試行地域と次の段階

Unified EA Co-sell は、前年 11 月に試行を開始し、発表時点では約一年が経過しています。対象は英国、米国、オーストラリアで、参加パートナーは 15 社です。

当該年度中は試行を続け、課題を調整する方針です。FY28 には対象国とパートナーを広げたいという見通しを示しました。確定した全世界向けの一般提供日ではありません。

相談先として MAICPP エリアの MAP 01 を案内しています。そこでは Unified Broker、Unified EA Co-sell、Unified for Partners を扱うとの説明でした。

## 6. デモ・手順

このセッションでは画面を使ったデモは行われていません。プログラムの仕組みと、金額例、顧客事例の説明が中心です。

参加に関して語られた行動は、次のとおりです。

1. Scale Solution Provider としての対象性を確認します。
2. Partner Development Manager（パートナー担当マネージャー）へ相談します。
3. 例外の相談や詳細確認が必要な場合は、担当者または MAP 01 で確認します。

申請画面、契約書の記入、インセンティブの請求操作は説明されていません。

## 7. 注意点・発表者の気付き

> 注意：Unified Broker Program と、試行中の Unified EA Co-sell を同じ提供状態として扱わないでください。3%・4% のインセンティブは後者の説明です。

また、パートナーが請求を担当することと、サポートそのものを提供することは別です。Unified の提供責任は Microsoft にあります。

今後の地域拡大や売上見込みには、登壇者の期待も含まれます。確定条件は発表だけでは分からないため、担当者への確認が必要です。

## 8. 利用者にとっての利点

顧客は、既存の取引先を通じて Unified を購入し、ライセンスや Azure と合わせて契約を整理できます。請求の柔軟性や、パートナー独自の支援を組み合わせられる点も利点です。

CDW の事例では、Microsoft とパートナーが予算を踏まえて提案を組み立て、顧客が望んでいた Unified と付加価値サービスを両立しました。

## 9. まとめ

Unified Broker は契約と請求の経路を広げ、Unified EA Co-sell は需要発見からの営業協業を報奨する取り組みです。顧客接点を持つパートナーの強みを、サポート提案にも生かす狙いがあります。

検討する際には、参加資格、試行地域、手数料とインセンティブの違いを分けて確認してください。
