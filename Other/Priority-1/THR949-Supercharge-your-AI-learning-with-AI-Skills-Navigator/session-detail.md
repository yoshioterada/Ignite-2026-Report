# THR949 Supercharge your AI learning with AI Skills Navigator

## 1. はじめに

このセッションは、Microsoft が無料で提供する AI の学習サービス **AI Skills Navigator** を、ライブデモで紹介する約 25 分のシアターセッションです。学習者として自分のスキルを伸ばす使い方と、組織のリーダーとしてチームの学習を進め、把握する使い方の両方が説明されました。

デモは、営業リーダーの「Sydney」というペルソナを演じる形で進みます。AI によるプレイリストの作成、音声のポッドキャスト化、音声での対話練習、ハンズオンラボ、バッジによる資格、組織向けのレポート、Copilot の learning agent が順に紹介され、その中には Ignite で新しく始まった・発表された機能も含まれています。**発表では、デモで見せた内容はすべて無料で、当日から利用できる**と説明されています。

セッション URL: [https://ignite.microsoft.com/en-US/sessions/THR949](https://ignite.microsoft.com/en-US/sessions/THR949)

## 3. 何に関する発表か

AI Skills Navigator は、AI を基礎から学び、スキルを身につけるための、Microsoft の無料のサービスです。Kavitha 氏は、よく聞く悩みとして次の 4 つを挙げています。

- 学習の場所がどこにあるのか分からない。
- 最も速く効率的に学ぶ方法が分からない。
- 変化の速度に付いていけない。
- 組織のリーダーとして、チームや組織が必要なスキルを身につけているかを確認したい。

これに対する設計の考え方として、次の 4 つの柱が示されました。

| 柱 | 内容 |
| ---- | ---- |
| AI によるパーソナライズ | サービス全体に AI が組み込まれ、学習を個人に合わせる |
| 仕事の流れの中でのスキル習得（in the flow of work） | 仕事をしている場所で学べるようにする |
| 実践（practice） | 学んだことを試し、適用する体験を用意する |
| 組織での拡大 | 組織のスキル習得を追跡し、支援するための洞察とツールを提供する |

デモの流れは、プレイリスト → モジュールの要約とポッドキャスト → 実践練習 → プレイリストの共有とチームの進捗 → 既製のプレイリスト → ハンズオンラボ → 資格（バッジ） → 組織のレポート → Copilot の learning agent、の順でした。

## 4. 発表者が伝えたいメッセージ

発表の締めくくりでは、AI による個人に合わせた体験、仕事の流れの中での学習、実践、組織での追跡と支援という 4 つの面が、**1 つの製品にまとまっている**ことが強調されました。Kavitha 氏は、セッションの終わりまでに、学習者として AI のスキルを高める方法だけでなく、チームや組織のスキル習得を支援する方法も持ち帰ってほしいと述べました。

また、「聞くだけ、読むだけでは学習が定着しない。実際に練習し、手を動かして初めて身につく」という考えが語られています。Kavitha 氏も、学ぶだけでは足りず実際にやってみたい、という声を多くの利用者から聞いていると述べ、AI Skills Navigator には実践して適用するための仕組みが組み込まれていると説明しました。

## 5. 発表内容の詳細

### 5.1 プロフィールと「For you」ページ

サインアップ時に、**役割（role）と学習の好み（learning preferences）**を入力すると、以後は AI Skills Navigator に戻るたびに、その役割に関連するコンテンツが表示されます。デモのペルソナは、インタラクティブな学習者で、動画や音声が好きな営業リーダーという設定でした。

### 5.2 パーソナライズされたプレイリストの作成

Ignite で新しく始まった機能が、**パーソナライズされたプレイリストビルダー**です。「For you」ページでプロンプトを貼り付け、create playlist を押すと、AI が関連するコンテンツを集め始めます。

- デモでは、顧客との打ち合わせの準備をしたいという内容のプロンプトを使った。
- 前日の夜に行った会話の例では、数回のやり取りだけで、コンテンツだけでなく、本人が求める成果も AI が把握していた。役割と学習の好み、情報をまとめる必要があること、営業ワークフローを学ぶ必要があることを踏まえている。
- 作成したプレイリストは、まったくカスタマイズしなくても、複数の形式（modality）のコンテンツが入っていた。

Kavitha 氏は、これと同様のものを、学習管理者や L&D 部門は手作業で集めており、数時間から数日かかると指摘しました。Vaishali 氏がかけた時間は 2、3 分です。以前は、あちこちで情報を探してブックマークしても、見返すことがなかったと話しています。

### 5.3 モジュールの AI 機能：要約とポッドキャスト

プレイリストの最初のモジュール（AI ワークフローの強化）では、モジュールが AI の機能で「生きた」ものになることが示されました。

- モジュール全体の要約を見られる。
- モジュール全体を**ポッドキャスト**にできる。

Kavitha 氏は、学習者に話を聞いて分かったこととして、**学習の形式（modality）が重要**だと述べています。短い動画を好む人もいれば、犬の散歩中にポッドキャストを聞きたい人もいます。特にニューロダイバースな学習者が、他の形式より、ポッドキャストを好む方法の上位に挙げるそうです。

デモでは、ポッドキャストの冒頭が実際に流れました。内容は、四半期レポート、リーダーシップ向けの資料、ステータスメールが月曜に締め切り、というプレッシャーの中で、「Microsoft Copilot が話に入ってくる」という導入でした。

### 5.4 実践練習（音声モード）

次に、Ignite で当日に公開された新機能として、実践の機能が紹介されました（機能名は音声からは聞き取れませんでした。最後のまとめでは "practice boost" の公開プレビューに触れています）。

- 例として、「データの分析と可視化」のスキルを選び、自分に関係のある業界を選ぶ。
- 選んだ業界について、関連するシナリオが取り込まれ、学びの定着を助ける。
- テキストのチャットもできるが、デモでは**音声モード**で練習した。

デモの内容は 6.2 にまとめています。Vaishali 氏は、従来は教材を読み、複数選択の知識チェックを受けるだけで、多くは当てずっぽうで、顧客との会話に自信が持てなかったと話しました。この機能では、安全でコーチされる環境で、焦らされず、評価されず、何度でもやり直せるため、自信が付いたとのことです。

Kavitha 氏は、これは多くの学習者から聞いた実際の学び方、つまり誰かに概念を説明させ、知識を試し、正しい方向へ導いてもらう形に近いと補足しました。行き詰まったときも突き放さず、ヒント、最後は答えの提示まで助けてくれます。テキストと音声の両方があり、いちばん楽な方法を選べます。

### 5.5 プレイリストの共有とチームの進捗

プレイリストは、個人の学習で終わりません。作ったプレイリストを**チーム全体に割り当て**、チームの進捗を**共有ビューで確認**できます。デモでは、Cora という人に学習を促す必要があるという例が出ました。

### 5.6 既製のプレイリスト（featured playlists）

何を AI に聞けばいいか分からない人のために、すぐ使える featured playlists が用意されています。チームのメンバーに割り当てて、AI の学習を始めさせられます。

- 初心者向けから、FinOps や tokenomics のコスト管理まで、並べ替えと絞り込みができる。
- 当日の朝から、Ignite の基調講演で話された話題の新しいプレイリストが公開されている。

### 5.7 ハンズオンのオンデマンドラボ

よりテクニカルなメンバー向けに、Ignite で当日に始まったのが **hands-on on-demand labs** です。完全に無料で、セットアップもサブスクリプションも不要で、AI Skills Navigator の中でラボを体験できます。ラボの完全なデモはこのセッションでは行われず、詳しい内容は後の深掘りセッションで扱われるとのことです。ラボは今後も継続的に追加される予定です（追加先は発話では "ASQ" と聞こえ、音声認識の都合で表記が確定できません）。

登壇者は、利用者から最も多い質問は「これは無料か、有料の層やサブスクリプションがあるか」だと述べ、**今日見せたものはすべて無料で、当日から利用可能**だと答えています。

### 5.8 資格：Microsoft Pro badge

資格のページには、認定資格（certifications）と applied skills が表示されます。最近始まった **Microsoft Pro badge** は、試験を受ける必要がありません。

1. GitHub Copilot を日常的に使う。
2. 使用状況から、習熟度（proficiency level）が付与される。
3. AI Skills Navigator に戻って、バッジを申請（claim）する。
4. **Credly** との連携で、ネットワークに共有できる。

この取り組みは GitHub チームと緊密に協力して進めたもので、暗記ではなく、実践的なスキルを示せることを証明する方向の資格だと説明されました。

### 5.9 組織向けのレポート

当日発表された機能として、組織全体の**最初の org reporting rollup** があります。適切な権限を設定すると、データは Microsoft の方針どおり、既定でプライベートかつ安全です。

見られる情報は次のとおりです。

- 組織の学習者と、それぞれの学習の進み具合
- 資格の取得状況（試験を準備している人、すでに資格を持っている人）
- プレイリストの利用状況（グラフと傾向、ギャップ）
- 学習者が学んでいるコンテンツと、得ているスキル

Vaishali 氏は、見えたものについてコーチングできるため、リーダーとして役立つと述べました。発表者は、ROI の話をよく議論するとして、事業成果を目指さないスキル習得は事業には必要ないと述べ、組織の AI スキルが向上するにつれて、事業の成果もそれに結びつけて見られると説明しています。リーダーにとっては、技術を学ぶだけでなく、人の役割にどう適用されるかという実践的な成果が重要だという考えです。

### 5.10 Copilot の learning agent

Web で無料で使える AI Skills Navigator に加えて、**Copilot の learning agent に AI Skills Navigator を統合した**ことが発表されました。Copilot を使っているユーザーは、他の場所に移動せずに、必要なときにその場でスキル習得を受けられます。

- learning agent は、agent store から無料で入手できる。
- AI Skills Navigator 以外のコンテンツも含めて提供している。
- 資格、学習、スキル習得のセッションも、Copilot 内で見つけられる。

## 6. デモ・手順

このセッションには、Vaishali 氏によるライブのデモがあります。録音は音声のみのため、語られた範囲で整理します。Sydney という営業リーダーのペルソナで進みました。

### 6.1 プレイリストの作成と利用

1. AI Skills Navigator の「For you」ページを開く。
2. 顧客との打ち合わせに備えるためのプロンプトを貼り付け、create playlist を押す。AI が関連するコンテンツを集め始める。
3. 時間の都合で、前日の夜に行った会話の画面に切り替える。数回のやり取りで、コンテンツと目的に合ったプレイリストができている。
4. 作成したプレイリストを保存し、開く。多様な形式のコンテンツが入っている。
5. 最初のモジュール「AI ワークフローの強化」を開き、要約を表示する。
6. モジュールをポッドキャストにして、冒頭を再生する。

### 6.2 音声モードでの実践練習

1. 「データの分析と可視化」のスキルで、業界を選ぶ。選んだ業界のシナリオが表示される。
2. 音声モードで AI と会話する。デモで語られたやり取りは次のとおり。
   - ユーザー: 大きな Excel のワークブックに予測があるが、営業レポートがばらばらで、共有できる形にしたい、と答える。
   - AI: あと少しだと促し、ばらばらのファイルを統合して、出典付きの調査結果を共有可能なレポートにする必要性から、最適なツールについて何が言えるかを問う。
   - ユーザー: ファイルをまとめ、複雑なデータ入力を分析できるツールだと答える。
   - AI: ファイルの範囲と複雑さに対して正しい方向だと認め、どの Microsoft のツールを選ぶか、出典付きで共有可能なレポートというニーズにどう合うかを問う。
   - ユーザー: 分からないのでヒントを求める。
   - AI: 作業が 1 つのワークブックの中で完結するかどうかを比較するように、とヒントを出す（発話はここで途中までです）。
3. このやり取りでは、具体的なツール名は語られていません。

### 6.3 プレイリストの共有と進捗

1. 作成したプレイリストを、チーム全体に割り当てる。
2. チームの進捗を共有ビューで確認し、遅れている人（デモでは Cora）に声をかける、という例を示す。

### 6.4 そのほか

featured playlists、Microsoft Pro badge、org reporting は、画面を見せながら説明されましたが、操作の手順までは語られていません。hands-on labs は「詳しいデモは別のセッション」とされました。Copilot の learning agent は、画面を見せたかどうかも発話からは分かりません。画面の細部は音声からは確認できません。

## 7. 注意点・発表者の気付き

- ラボの詳細なデモは、このセッションでは行われていません。別の深掘りセッションがあると案内されました。
- 組織向けレポートを見るには、**適切な権限の設定**が前提です。データは既定でプライベートかつ安全と説明されています。
- 学習の形式の好みは人によって異なるため、動画、ポッドキャスト、テキスト、音声など、複数の形式を用意することが重要だという学びが語られています。
- 実践機能の正式な名称は、音声からは確認できません。

## 8. 利用者にとっての利点

発表で語られた利点は次のとおりです。

- **無料で、当日から使える。** デモで見せたものは、すべて無料と説明されている。
- **準備時間の短縮。** 学習管理者が数時間から数日かけて手作業で集めるプレイリストを、数分で作れる（デモでは 2、3 分）。
- **自信につながる実践。** 安全でコーチされる環境で、評価されることなく何度でも練習できる。
- **学習形式の選択。** 動画、ポッドキャスト、テキスト、音声から選べる。特にニューロダイバースな学習者に好まれると説明された。
- **試験なしの資格。** GitHub Copilot の利用から Microsoft Pro badge を取得し、Credly で共有できる。
- **組織の可視化。** 学習者の進捗、資格、プレイリストの利用、スキルを組織全体で把握でき、ROI の議論にもつなげられる。
- **仕事の場での学習。** Copilot の learning agent から、移動せずに学べる。

## 9. まとめ

AI Skills Navigator は、AI により学習を個人に合わせ、Copilot や Web の仕事の場で学べるようにし、プレイリスト、音声練習、ラボ、バッジで実践を支え、組織のリーダーには学習の追跡と支援の手段を提供する、無料のサービスです。Ignite では、プレイリストビルダー、実践の新機能、ハンズオンラボ、Microsoft Pro badge、org reporting、Copilot の learning agent が紹介されました。質問があれば、期間中の他のセッション、青いジャケットのスタッフ、Skills Hub で聞けると案内されています。アカウントは、手元のスマートフォンか Skills Hub で作成できます。
