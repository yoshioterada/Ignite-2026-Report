# THR953 Learn in the flow of work with Microsoft Copilot + AI Skills Navigator

## 1. はじめに

このセッションは、Microsoft Copilot の中で「仕事の流れの中で」AI スキルを学べる **Copilot Learning Agent** と、そこにつながる学習ポータル **AI Skills Navigator** を紹介する 25 分のシアターセッションです。Copilot を使い始めたい個人、そして社内でのスキル習得の進み具合を見たいリーダーに向けた内容になっています。

発表は、二人の登壇者が寸劇のように掛け合いをしながら、営業担当者が Copilot に「トレーニングを受けたい」と尋ねるところから、オンボーディング、スキル学習、プレイリスト、リーダー向けのレポートまでを画面で見せていく構成です。登壇者の一人（Raymond 氏）が、このツールの助けで 16 営業日かかる見込みだった社内アプリを 2 日で作った、という実体験も語られます。

## 3. 何に関する発表か

テーマは、**学習を仕事から切り離さず、Copilot の中で、仕事のニーズから始めること**です。発表者は「in the flow of work」という言葉を繰り返しました。

Copilot Learning Agent は、アセスメント、パーソナライズ、そして AI Skills Navigator のリソースを使って、エンタープライズ向けの学習パスを提供するエージェントだと説明されています。AI Skills Navigator は、学習者とリーダーがスキルを伸ばし、投資対効果（ROI）が出ているかを大規模に確認するための場所で、**無料**だと発表者は強調しました。QR コードからサインインすると、学習内容は引き継がれるとも話しています。

流れは次のとおりです。

1. 導入：Copilot に懐疑的な営業担当の例
2. 画面での説明：Copilot でトレーニングを尋ねる、オンボーディング、スキル学習、プレイリスト
3. リーダー向け：利用レポートと、組織独自のナレッジソースの管理
4. 実体験の紹介とまとめ

## 5. 発表内容の詳細

### 5.1 導入：Copilot に懐疑的な営業担当

寸劇では、1 日にとても長く働く Raymond 氏が、Copilot について「ハルシネーションが怖い」「ほかのツールも含め、新しいツールを一から学ぶ時間がない」と話します。設定として、二人は e バイクの新規事業を始めていて、Raymond 氏は営業を担当しているという役柄です。

これに対して、案内する側は「自分も以前は同じ気持ちだった」と答えます。ただ、使い始めて役立つ方法を見つけるうちに、使う機会が増えました。きっかけは、**仕事の流れの中で学び始めた**ことだと説明されています。

### 5.2 Copilot で「トレーニングを受けたい」と聞く

最初に行ったのは、Copilot にトレーニングを尋ねることでした。結果が分からないまま、「ここに聞くのが自然だと思った」と話しています。Copilot は幅広い提案を返しましたが、その中で目を引いたのが、**「learning agent というエージェントを使うとより良い結果が得られるかもしれない」**という提案でした。

### 5.3 Learning Agent でのオンボーディング

Learning Agent は、Copilot の本格的なオンボーディング体験の場であり、Copilot の使い方を学ぶための道筋が用意されています。主な点は次のとおりです。

- **仕事の要約が最初に返ってくる。** 営業職で e バイクの販売やビジネス開発を行っている、という本人の役割と、仕事上のアクティビティやデータに基づいたもの。エコシステム全体と統合されているため、最初からパーソナライズされている
- 気に入ればそのまま進め、気に入らなければ変えたい点を伝えられる
- 先ほどの Copilot の回答は情報量が多かったのに対し、こちらは消化しやすい。**所要時間は 6 分**と表示される

### 5.4 実際の仕事で学ぶ

エージェントはまず、日々の仕事に基づく実務タスクを提案します。ここでは、Thunderbolt e バイクのアウトリーチ計画の例が使われました。

1. 販売先になりそうな店舗を特定し、フォローアップメッセージのドラフトを依頼する（事前に実施済みで、その結果を見せた）
2. メッセージをただ返すのではなく、**良いプロンプトの要素（コンテキスト、ゴール、ソース）**を教えてくれる。これにより、自分で何を提供すればよいかが分かる
3. さらに、エージェントが実行まで申し出てくれる。結果として最初のドラフトを受け取る。そのまま使わず自分で手を入れるつもりだが、出発点として時間の節約になった
4. 次の話題として、**Microsoft 365 アプリ（Word、PowerPoint、Excel）で仕事を進める**方法が示される。基本的な提案に加えて、AI Skills Navigator のより深いリソースも示される。AI Skills Navigator は、Microsoft Learning への無料の入り口（front door）だと説明された

学習が目的の画面で、同時に仕事も進む。これが「flow of work」の意味だというのが発表者の説明です。

### 5.5 エージェントの紹介、AI ガイドライン、ナレッジチェック

- **エージェントの紹介**：「analytics」（聞こえた綴り）や researcher など多くのエージェントがあり、「どれをいつ使えばよいか」が分かりにくい、という悩みが語られました。Learning Agent では、例えば researcher が営業担当に何をしてくれるのかを簡潔に把握でき、必要なら深掘りできます
- **AI ガイドライン**：責任ある使い方、データの適切な扱い、出力の利用と共有の仕方が示される。この会社は、デジタルテック業界向けのコンプライアンスの資料も整備しているところで、それをここに読み込ませてあり、エージェントが自社のポリシーを教え、営業職の自分にどう当てはまるかを説明する
- **ナレッジチェック（アセスメント）**：理解度を確認する質問が出て、結果に基づいてコーチングが返ってくる。デモでは質問は 3 問で、短く、集中を保てる程度の分量だった。終了後は結果が表示され、完了すると「金の星をもらった」ような気分になり、続きのリソースが示される

### 5.6 学習を続ける：Weekly streaks、Daily Copilot tips、Discover

オンボーディングの後に、さらに続けられる要素が紹介されました。

| 機能 | 内容 |
| --- | --- |
| Weekly streaks | 週ごとに戻ってくる動機づけになる。Copilot が頻繁に変わるため、最新の状態を維持する助けになる |
| Daily Copilot tips | 例として、パフォーマンス指標をステークホルダーに追跡・報告する、という自分の仕事に結びついたヒントが挙げられた。思いつかなかった使い方に気づける |
| Discover | AI スキルに加えて、ほかのスキルも伸ばせる。学びたいスキル（ここではピープルスキルと聞こえますが、聞き取りが不明瞭です）を Learning Agent に伝えておくと、プロファイルを手がかりに推薦される |

Discover では、スキルの学習計画や知識のアセスメントを受けられます。例として **LinkedIn Learning のロールプレイ**が紹介され、厳しい顧客との商談の前に、やり取りを練習できます。フィードバックも返ってきます。資格（certification）の取得にもつながり、「習得を示せる」「どこへ行っても付いてくる」とキャリアの観点が語られました。

### 5.7 AI Skills Navigator のプレイリスト

**Explore playlist** からは、AI Skills Navigator のプレイリストを探せます。AI Skills Navigator には、AI のスキルアップと Microsoft のさまざまなトレーニングテーマに関する、注目のプレイリストのライブラリがあり、それが Learning Agent の中に表示され、シームレスにアクセスできます。

デモでは **「Delegate work to AI」** というプレイリストが選ばれました。営業職の自分にどう関係するかが分かり、Microsoft が推奨するやり方なので信頼できる、という説明です。開く前に内容をプレビューできます。

- **進捗は消えない**：Copilot のチャット履歴に残り、AI Skills Navigator でも、次に開いたときに続きから再開できる
- **学習コンテンツは Copilot の中で見られる**：別の場所に移動せずに、コンテキストを切り替えないで済む
- **形式を選べる**：動画、テキストと画像、**要約**（発表者は「cliff notes」のようなものと説明）、**ポッドキャスト**（学習内容を音声にして、皿洗いや e バイクのテスト走行中に聞ける）
- **Practice**：学習の最後に、「自分と同じ名前の」AI のバーチャルトレーナーと練習シナリオに取り組む。トレーナーが課題を投げて理解度を確認する。難しく、理解を深く考えさせられるが、自信にもつながる、という感想が述べられた

### 5.8 リーダー向け：レポートとナレッジソース管理

チームに広げる場合の機能として、2 点が紹介されました。

**レポート**：エージェントの利用状況を見られます。

- 誰が使える（eligible）か
- 何人が見つけ、使い始めたか
- エンゲージメントのレベル、再訪問、繰り返しの利用
- アクティビティの種類：スキルアセスメントの受験、**exploratory learning**（学習の探索）、**applied learning**（学習を完了して実践したもの。デモで見せたフォローアップメールのドラフト作成が例として挙げられた）

これにより、チームのスキルアップへの投資対効果と、日々の仕事の中での進捗を把握できる、と説明されました。

**エージェントの管理**：管理画面では、組織独自のナレッジソースを管理できます。例として、同僚の持つ営業・マーケティングの SharePoint にあるトレーニング資料を、**アセスメントのグラウンディングソース**として使えることが示されました。これにより、社内のトレーニングと最新の Microsoft のトレーニングを同じ場所で提供できます。

> 補足：この管理画面の場面では、画面の読み込みを待つようなやり取りがあり、発表者が「デモではない」と冗談めかして話しています。画面の細部は音声からは確認できません。

## 6. デモ・手順

このセッションでは、画面を使ったデモ（寸劇仕立ての操作の説明）が行われています。ただし、録音からは画面上の操作の詳細（ボタン名、入力文言など）は分かりません。語られた順に整理します。

1. Copilot でトレーニングを依頼する。Copilot が幅広い提案を返し、その中で learning agent を勧める
2. learning agent に移る。役割（営業）と仕事のアクティビティに基づく仕事の要約が表示される。承認するか、変更したい点を伝える
3. 6 分のトレーニングを開始する。実務タスク（Thunderbolt e バイクのアウトリーチ計画）が提案される
4. フォローアップメッセージのドラフト依頼（事前実行済み）の結果を見る。良いプロンプトの要素を学び、エージェントに実行してもらい、最初のドラフトを得る
5. Microsoft 365 アプリでの仕事の進め方、エージェントの紹介、AI ガイドラインへと進む
6. ナレッジチェックを 3 問受け、結果とコーチングを確認する。オンボーディングが完了する
7. Weekly streaks、Daily Copilot tips、Discover の画面を紹介する
8. Explore playlist から「Delegate work to AI」を開き、プレビュー、要約、ポッドキャスト、Practice を紹介する
9. リーダー向けのレポート画面と、エージェントの管理画面（ナレッジソース）を紹介する

## 7. 注意点・発表者の気付き

- **Copilot への懸念が出発点**：寸劇の中で、ハルシネーションへの不安と、学ぶ時間のなさが挙げられました。これに対する答えとして、仕事のニーズの中で学ぶ形が示されています。
- **出力はそのまま使わない**：Raymond 氏は、Copilot が出したドラフトは、コピー＆ペーストせず自分で手を入れて使うつもりだと話しました。
- **学習の保存と継続**：学習の進捗は消えず、Copilot のチャット履歴と AI Skills Navigator から再開できます。
- **組織独自の資料の扱い**：社内のコンプライアンス資料や SharePoint のトレーニング資料を使う例が示されましたが、設定の詳細手順は発表では説明されていません。

## 8. 利用者にとっての利点

発表で語られた利点は次のとおりです。

- **学習が仕事と同時に進む**：実際の業務タスク（フォローアップメッセージの作成など）を題材に、Copilot の使い方を学びながら成果物も得られる
- **パーソナライズされる**：役割と仕事のアクティビティ、データに基づく。学びたいスキルを伝えておくとプロファイルが活用される
- **学び方を選べる**：動画、テキスト、要約、ポッドキャスト、Practice
- **リーダーが進捗と ROI を把握できる**：利用状況、エンゲージメント、アクティビティの種類のレポートがある
- **自社の知識と Microsoft の知識を同じ場所で**：社内のナレッジソースを、アセスメントのグラウンディングに使える
- **無料**：AI Skills Navigator は無料と繰り返し説明された
- **実体験**：Raymond 氏は、約 2 日前に、社内アプリケーション（16 日で仕上げる必要があった）の作成で、Learning Agent を使いながら進めた。アプリの構造の組み立てから、エージェントを使ったスキャフォールドと完成までを、仕事の流れの中で教わり、**16 営業日分の作業を 2 日に短縮**できた。そのおかげで、この登壇の準備に集中できたと述べている

## 9. まとめ

Copilot Learning Agent は、「Copilot に学びたいと尋ねる」ところから、仕事に基づくオンボーディング、AI ガイドラインとナレッジチェック、継続的なスキル学習、AI Skills Navigator のプレイリスト、そしてリーダー向けのレポートまでを 1 か所につなげるものとして紹介されました。

学ぶために仕事を止めるのではなく、仕事の中で学び、同時に成果も得る、というのが一貫したメッセージです。AI Skills Navigator は無料で、QR コードからすぐ使えます。発表者は、これらのツールを使って AI の進化に追いつき、さらに先へ進んでほしいと呼びかけました。
