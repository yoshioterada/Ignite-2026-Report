## 1. はじめに

このセッションは、Microsoft のパートナー企業に向けた、AI ビジネスソリューションの市場展開と収益機会の説明です。Microsoft の営業組織の責任者による戦略の説明、製品担当者による Microsoft 365 Copilot の新機能と収益機会の紹介、パートナー 2 社との対談、そしてパートナー向けの特典と依頼事項、という流れで進みます。

### 5.2 市場展開の 3 つの流れ

Andrew は、今後の市場展開の土台として 3 つのテーマを挙げました。

1. **全従業員に AI を。** 参入の障壁を下げ、AI をスタック全体に行き渡らせる。
2. **個人の生産性から、業務プロセスの変革へ。** 前日の CIO サミットで Agent 365 を 4 時間デモした際、監視や統制の方法だけでなく、事業成果にどう結び付けるかが最も聞かれたと述べています。
3. **AI の所有を、IT と事業部門で共有する。** この日に発表された Agent 365 の事業分析アプリ（business analytics）により、AI の利用状況と価値の測定が事業部門に渡る、という説明です。一方で、エージェントと AI 全体の観測面には、堅牢な管理とガバナンスも引き続き必要だとしています。

パートナーへの期待は 3 点でした。大規模な顧客の戦略的な変革リーダーであること（顧客は Microsoft の営業担当に加えて、場合によってはその代わりにパートナーの声を聞く、という冗談も交えています）。業界の深い知見に基づく、エージェント型で拡張可能な独自ソリューションを提供すること。そしてそれを繰り返し実施して、価値実現までの時間を短縮することです。

### 5.3 ME7 Plus と 4 つの会話領域

Andrew の組織は、現場の営業担当向けに、イネーブルメントと市場展開の戦略を作っています。パートナーは、AI ワークフォース担当と AI ビジネスプロセス担当のスペシャリストや、ソリューションエンジニアと日々連携しています。

SLT（経営幹部）の発表のとおり、Microsoft のフロンティア AI の市場展開は、インテリジェンスと信頼に基づいています。

- **インテリジェンス**：Copilot と、インフラ基盤全体にわたる拡張性。ME5 のコアツール群が、組織が AI 基盤で使えるインテリジェンスの土台になります。
- **信頼**：ME7 バンドルに含まれる Agent 365 と Entra Identity Suite。Copilot のインテリジェンスを使っても、Agent 365 と各種セキュリティツールで観測でき、自社に適していて事業成果を出せると確認できなければ、顧客は信頼できないという説明です。

**ME7 Plus** は、これらの製品に、**消費ベースの利用**を加えたものです。Cowork のような、長時間動く作業や複雑な業務プロセス、Autopilot、Code、全員がメーカー（作り手）になる、といった用途が消費に結び付きます。現場の営業の取り組みと、それを拡大するパートナー向けの取り組みは、この ME7 Plus に合わせられます。

営業担当は、製品の販売としてではなく、次の 4 つの会話領域で顧客と話すように位置付けられます。

| 会話領域 | 内容 |
| --- | --- |
| フロンティアワークフォース | AI を全員に広げ、エージェントや Autopilot の価値で組織の生産性を高める。ME7 Plus の消費につながる入口 |
| フロンティアの保護とエージェント管理 | エージェントが急増する中で、知性と信頼の枠組みに沿って、保護と管理の会話を行う |
| 経済性と FinOps | 観測面の一部として重要になる、費用の議論 |

> 補足：後半で 4 つの領域名は「フロンティアワークフォース、フロンティアの保護、エージェント管理、AI の経済性と FinOps」と読み上げられています。最初の説明では「保護」と「エージェント管理」が続けて語られたため、1 行にまとめました。

### 5.4 Microsoft 365 Copilot の新機能（担当：Inder）

Inder は、9 月に発表された内容が Ignite で実際に使えるようになったことと、パートナーが収益を得る機会の 2 点を話しました。

#### 4 つの仕事の型

| 型 | 説明 | 対応する機能 |
| --- | --- | --- |
| 支援（Assist） | AI が作成を助ける | Chat：質問への回答、内容の分析、日常業務の支援 |
| 委任（Delegate） | 仕事を定義し、AI が実行する。人は導き、結果を磨く | Cowork：アプリ、スキル、コネクタをまたぐ、長時間・複数ステップの作業を委任する |
| 構築（Build） | 自然言語で伝えると、動く解決策を AI が作る | Code：ナレッジワーカーがアイデアを動く解決策にする |
| 自動化（Automate） | 方向性とポリシーを決め、エージェントが作業を続ける | Autopilot：定められた権限と統制の範囲で、作業を進める能動的なデジタルチームメイト |

Microsoft Copilot はこれらを 1 つのアプリにまとめます。Satya Nadella がこの日の朝に呼んだとおり、「仕事のためのオペレーティングシステム」だと説明されました。

#### 提供状況

| 機能 | 状況（発話のとおり） |
| --- | --- |
| Home、Chat、Cowork、Office in Copilot | Ignite で一般提供（GA） |
| Code | GA（発話では Autopilot と並べて「Frontier」の文脈で語られ、そのうえで GA と述べられています） |
| Autopilot | Frontier Public |
| モデル別の支出・使用状況の分析（委任されたアクセス、カスタムレポート、部門別チャージバックを含む） | Frontier Public |
| Agent 365 の business value analytics ダッシュボード | Frontier Public |

Inder は、**これはロードマップではなく、出荷されているもの**であり、顧客は今四半期から体験できると述べています。

#### 課金モデル

| モデル | 位置づけ |
| --- | --- |
| 日常の AI（Everyday AI） | ユーザー単位の購読ライセンスで固定価格。CMO の言葉として、固定価格で最高の価値が得られる、と紹介されました。予算は IT が持つことが多い |
| 高度な AI（Advanced AI） | 使用量ベースの課金。最高のモデルや機能が必要なときに柔軟に使える。Cowork、Code、Autopilot などの体験がここに当たる。予算は、価値を生む事業部門が持つ例が増えている |

日常の AI については、AI の進歩に合わせて、より多くの価値を移していく方針だと述べています。

#### 製品の見せ方（画面を使った説明）

画面を示しながら、次の点が説明されました。

- Home タブには Chat と Cowork があり、この日から、作業を取り込んで、Chat で実行すべきか Cowork で実行すべきか、最適なモードを判断する機能が提供される。まもなく、必要に応じて作業をモード間で委任・移動する、より高度な機能を加える予定。Home が中心になる。
- Code は、多くの人が意外に思う機能。ナレッジワーカーの間でも「作る」ことが当たり前になる、という見込みを持っている。Excel が数字を財務部門から運用やマーケティング担当に広げたように、Code は構築を広げ、ダッシュボードや小さなアプリを平易な言葉で作れる。
- Autopilot は、24 時間 365 日、利用者に代わって働く自律的なデジタルチームメイト。名前、役割、目標を与えると、Teams、Outlook、チャネル、ドキュメントに現れ、同僚のようにメンションできる。顧客のテナントに置かれ、固有の ID、実際の権限、監査、ガバナンスを持つ。チャネルの監視、スレッドのフォローアップ、プロジェクトの再開などを、利用者の就寝中も行う。
- Office in Copilot は、これまでの「Office の中の Copilot」が、双方向になった。Copilot を 1 つのアプリとして、離れずに仕事を終えられ、離れても作業を引き継げる。

#### なぜ Microsoft か：差別化の 5 つの柱

機能、モデル、ベンチマークは毎日変わり、火曜日にモデルで勝っても木曜日に負けることがある、という前置きのうえで、Copilot が提供する持続的な価値が 5 つの柱で示されました。発表者は 3 つを取り上げています。

- **Work IQ**：顧客の組織の文脈を理解し、組織がどう動くかを理解するインテリジェンス層。
- **マルチモデル**：すべてのタスクに最も高度なモデルが必要なわけではなく、適したタスクに適したモデルを選べる。
- **セキュリティと管理**：セキュリティ、ガバナンス、組織の文脈が最も明確な差別化要因だと、複数のパートナーイベントで聞いた。ガバナンスされ、企業の文脈に根ざし、仕事に統合されたものとして位置づけ、この枠組みで会話を始めることを勧めています。

モデルが同質化し、価値がその周辺のシステムに移る中で、文脈、エージェント、ガバナンスが差別化を作ります。そこに、パートナーの機能面・業界面の専門性が入る、という説明です。

#### Gigaom による比較調査

第三者の Gigaom と実施した独立した調査が紹介されました。日常の 100 を超えるタスクと、高度な利用の約 140 のタスクで、Claude と ChatGPT とのコストを比較したものです。結果は、日常の AI で Copilot は Claude より約 **7 分の 1 のコスト**、高度な利用では約 **3 分の 1 のコスト**とのことです。要因として、auto モード（自動でモデルを選ぶ機能）の差別化が挙げられました。

#### Copilot アプリの変遷

7 月に新しいデザインを発表し、8 月に個人アカウントと仕事のアカウントを統合し、9 月に多くの機能を発表して、それが Ignite で稼働になりました。Home タブの Copilot は、すでにモード間の引き継ぎを始めています。今後は、作業をモード間で振り分ける機能が追加される予定です。

### 5.5 パートナーの収益機会：5 つの領域

Inder は、Copilot とエージェントのサービス収益は前年比 **53%**、エージェント関連の収益は前年比 **150% 超**の増加だと述べ、「稼げるか」ではなく「どこに投資するか」が問いだと位置づけました。5 つの領域は、顧客のフロンティアへの道のりを左から右に並べたもので、すべての土台に **AI センター・オブ・エクセレンス（AI CoE）**があり、継続的なマネージドサービスの機会になります。

| 領域 | 内容 |
| --- | --- |
| 1. アドバイザリー | 価値ベースの変革コンサルティング。パイロットを超えて、AI がどこで成果を出すかを知りたい顧客に、高 ROI のユースケースの特定と優先順位付け、KPI の定義、ビジネス価値モデルの構築を提供する。アドバイザリーを握るパートナーが、ロードマップとその下流を握る、という説明。 |
| 2. セキュリティ、ガバナンス、導入 | スケールにはデータの準備と保護が必要。ガバナンス、セキュリティ、品質を備えたデータ資産の準備、適切なグラウンディングでの Copilot の展開、対象を絞った PoC とパイロットで価値を示す。すべての顧客に必要な基礎作業。 |
| 3. エージェントの変革 | エージェントが各プラットフォームやチームに広がる中で、環境のガバナンスと次の開発を支援する。標準提供のエージェントの有効化、コネクタやプラグインの構築、部門別のスキルパックやカスタムエージェントの構築、エージェント運用（観測、管理、セキュリティ、ガバナンス）。 |
| 4. AI の FinOps | 新しい領域。支出の行き先の把握と、継続的な最適化。 |
| 5. 導入定着 | 技術は簡単で、行動を変えることが難しい。シナリオ別のスキル習得、プロンプト集、スキルパック、チェンジマネジメント。 |

AI CoE は、必要性を継続的に評価し、エージェント型ソリューションの対応づけと、すでにあるエージェントの整理を行います。これによって、プロジェクト収益がマネージドサービスの機会に変わる、という説明です。

### 5.6 AI の FinOps

Inder は、パートナーにとって新しく、最もわくわくする機会の 1 つだと説明しました。根拠として 2 つの調査を挙げています。

- McKinsey の調査では、93% を超える組織が AI の予算を超過している。
- BCG の調査では、80% を超える予算が IT の外にある。

Cowork など使用量で課金される高度な AI では、費用のガバナンスがなければ、パイロットも拡大もスケールできないという顧客の声があります。この日の基調講演で、モデル別の支出と分析、部門別のチャージバック、事業リーダー向けの委任されたアクセス、business value analytics アプリが発表されました。リーダーは、支出、使われているモデル、将来の費用の見通しを、平易な言葉で理解できます。

パートナーが収益化できる 3 つの領域は次のとおりです（左から右へ、市場が広がる）。

1. **AI の経済性に関するアドバイザリー**：「投資すべきか、どこに投資すべきか」に答える。費用予測、投資先への確信、ROI 分析、優先するシナリオのロードマップ。
2. **AI の経済性のガバナンス**：費用を継続的に管理するための、ポリシー、予算、ガードレールの設定。
3. **運用と最適化**：導入後に、AI が価値を出しているかを継続的に確認する。モニタリング、価値の追跡、四半期ごとのビジネスレビュー。

下部の短縮リンクで案内されている FinOps の実践開発ガイダンスを確認し、まだ着手していなければ実践の構築を始めるよう勧めています。

### 5.7 パートナー動画：Uberzuna

動画では、Uberzuna（音声認識による表記）が、データと電力の接続ソリューションの提供企業として紹介されました。語られた内容は次のとおりです。

- 従業員への AI の提供から始め、2024 年に Copilot のパイロット段階を開始した。当初から、ユーザーの導入支援とセキュリティ・ガバナンスに注力した。
- ユーザーの導入率は 90% 超で、拡大に進む指標の 1 つになった。
- 個人の生産性を超える目標を持っていた。**AI ファクトリー**は、エージェント型 AI の流れの基盤で、従業員からアイデアを集め、支援し、エージェントを作る場。協業が同じ場所でできるため、速く拡大できる。
- 次の段階が Cowork。エージェントは不要だがチャットでは足りない場面で、Cowork が価値を出す。
- 製造業であり、正確なコストの把握が重要。FinOps は監視だけでなく、予測や AI の展開の仕方を変えることにも役立つ。投資の回収を、できるだけ早くしたいため。
- 動画の最後の発言者（誰かは発話では確認できません）が、AI 変革の役割は、技術を人、プロセス、セキュリティにつなぎ、組織の能力を築くことだと述べ、この企業の取り組みを、AI を単なる技術プロジェクトの連続としてではなく、組織の能力を段階的に築いて価値を出す好例として紹介しています。

### 5.8 パートナー対談（司会：Anand）

Anand が、Boris（Companion Short）と Danny を迎えて、対談を行いました。Anand は、2 人とも自社と顧客の両方でフロンティア変革を進めていると紹介しています。

**顧客の関心と懸念（Danny）**
セキュリティは最大の関心事の 1 つで、Microsoft 365 Copilot でもそうでした。Cowork の GA に伴い Copilot クレジットが利用可能になったことで、費用管理が顧客の大きな懸念になっており、その統制を支援していると述べています。

**顧客の関心と懸念（Boris）**
ドイツ、オーストリア、欧州の市場が中心です。3 年前は「AI で何ができるか」でしたが、現在は「どう事業価値を出し、企業規模で拡大するか」に変わりました。ガバナンスとセキュリティが要であり、FinOps は、事業価値を費用と照らして、どこに投資するかを決める商業的な視点をもたらすとしています。

**社内での学び（Danny）**
Copilot は、地域法人として初日から導入できた最初の技術であり、そのためグローバルの CTO オフィスとつながりができた。Cowork が GA になってからは、予算は最初グローバルから来て、高価値のユースケースを探して CTO オフィスに戻す形だった。時間とともに、予算は法人単位に近づいた。現在は国ごとの予算と、イノベーター向けの予算があり、本人もそのグループにいる。段階的に、予算の詳細さと統制が増している、という話です。

**社内での学び（Boris）**
顧客ゼロであることは、長年の DNA。Copilot を早期に展開し、アクティブユーザーは早い段階で 97%。Agent 365 がプレビューになったときに自社に適用すると、600 人で 1,500 のエージェントが動いていたことが分かり、多くの顧客と同じ経験をした。Cowork とスキルが出た時には、チームに Cowork のスキルチャレンジを実施した。偶然にも、使用量ベース課金（UBB）が使えるようになる数日前で、商業面とガバナンス面の準備を急いで立ち上げる必要があった。学びは 3 つ：（1）商業とガバナンスの準備、（2）IT 以外の人がスキルでプロセスを自動化できること（多くの顧客に見られるパターン）、（3）12 のプロセス領域にわたる 50 のスキルを用意し、営業プロセスなどで価値を出す方法を顧客に見せられること。顧客ゼロは大変だが、助けになる、とも述べています。

> 補足：この後、司会の Anand が「FinOps を社内に展開すると専門性が得られる」と発言しています。これは Boris の発言ではなく司会者の発言です。

**今後 6〜12 か月の見通し（Danny）**
多くの顧客と取り組む経験から、業界知識や、自社で作ったスキルを顧客でも生かせる。長期的には、この日の朝に発表された IQ のように、エージェントやスキルの仕組みで、自社の IQ を売ることを見込んでいる。

**初めて取り組むパートナーへの助言（Boris）**
顧客の AI 変革は、プロジェクト型から**ジャーニー型**に移る好機。Copilot の技術面、導入定着とチェンジマネジメント、アドバイザリー、ガバナンスなどのスキルを実践の中に揃え、2〜3 年のジャーニーで顧客に助言できることが有益と述べています。

**Microsoft への依頼**
- Danny：パートナーには、膨大な変化を吸収する時間が必要。能力を築くために、時には時間をください。
- Boris：「データは新しい石油」と教わった。Microsoft が持つテレメトリのデータを（取り組んでいることは承知のうえで）顧客とパートナーに提供し、現在地、次に何をするか、何が必要かの感覚を持てるようにしてほしい。

Danny の要望に対しては、事前通知はしているが、通常は自分たちが変更を知る 5 分前だと冗談交じりに応じ、Boris の依頼にも、できる限り支援すると述べました。

### 5.9 パートナー向けの特典と依頼

対談後、Anand（と読める発言者）が重要な更新を説明しました。

#### MAICPP の特典

顧客ゼロになるために、MAICPP のメンバー特典が強化されました。**モダンワークの専門性認定ごとに、月ごとの Copilot クレジットがほぼ倍増**し、最大 3 つの専門性認定で **300,000 クレジット**、Copilot の専門性認定があれば、さらに **100,000 クレジット**で、合計で月に約 **400,000 クレジット**を自社の利用に使えます。これは、ME7 ライセンスと A365 の社内利用権（IUR）に加えたものです。IUR を知っている会場の参加者は少なく、最大限に使うよう促しました。

> 補足：発話では「MAICPP」と呼ばれており、正式名称の展開は語られていません。

#### トレーニング

EPC や Jumpstart を経験した人は少数でした。トレーニングを、さらに簡単にします。

- **AI First Value Bootcamp**：成果ベースの提供形式のトレーニング。営業と市場展開の担当者が、製品や機能の話から、役員との事業成果の話に移ること、営業とデリバリーのコンサルタントが業務プロセスの課題と最適化、ROI を特定し、ビジネスケースを作ることを目指す。
- **Titan ラーニングパス**（技術向け）：フロンティアワークフォース、フロンティアの保護、エージェント管理、AI の経済性と FinOps の 4 つの会話領域が対象。

どちらも 1 月から利用可能になる予定です。

#### CSP 向けの Copilot クレジット有効化オファー

顧客が ME7 を 300 席以上購入する場合、パートナーは、最大 **$7,500** 分の Copilot クレジットを顧客に提供できます。この日から **3 月 31 日**まで有効で、CSP パートナーは一定期間内に取引する必要があります。あわせて、従量課金と Azure サブスクリプションのセットアップを支援する必要があります。クレジットの心配で ME7 の会話が止まっていた状況を解消し、「手元に資金がある」入り口として、事業モデルの開発や ROI の話、次のプロジェクトにつなげる、という位置づけです。

#### 3 つの依頼

1. **自分自身が顧客ゼロになる**：A365、Copilot、Cowork、その他のエージェント型の変革を自社で使う。特典とリソースを活用し、営業とデリバリーの担当者に能力を持たせ、IP を築く。
2. **実践ガイドの活用、オファーの公開、スキル習得**：FinOps とエージェントのパートナー向けの実践ガイドは、製品の進化に合わせて更新している。オファーを市場に出していたら、営業担当が共同販売できるよう知らせてほしい。現在、FinOps オファーへの需要が高い。
3. **投資の活用**：Frontier Accelerate に顧客を指名した人を尋ね、挙手が見られなかったことに触れ、事前パッケージ化されたコンテンツがあり、Copilot の専門性認定があれば得られると説明した。専門性認定を取り、キットをダウンロードし、顧客を指名して価値を届け、新しい機会でアップセルする。CSP パートナーは CSP オファーで始められる。

最後に、EPC チャネルのコミュニティへの謝辞と、質問やフィードバックを歓迎する旨が述べられました。

## 9. まとめ

Microsoft の市場展開は、インテリジェンス（Copilot）と信頼（Agent 365、Entra）を軸にした ME7 Plus に集約され、フロンティアワークフォース、保護、エージェント管理、経済性と FinOps の 4 つの会話領域で進められます。製品は GA または Frontier Public の段階で出荷されており、課金は日常の AI（固定）と高度な AI（使用量）の 2 本立てです。

パートナーには、アドバイザリー、セキュリティ・ガバナンス・導入、エージェントの変革、AI の FinOps、導入定着の 5 つの収益領域があり、AI CoE が継続的なマネージドサービスにつながります。特に AI の FinOps は新しい機会です。実践のために、MAICPP の特典、1 月開始のトレーニング、3 月 31 日までの CSP 向けオファーが用意されました。**まず自社で使い（顧客ゼロ）、実践ガイドでオファーを作り、Frontier Accelerate の投資を活用する**ことが、最後の依頼でした。
