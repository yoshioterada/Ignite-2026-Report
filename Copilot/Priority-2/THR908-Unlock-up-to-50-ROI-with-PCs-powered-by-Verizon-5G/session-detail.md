# THR908 Unlock up to 50% ROI with PCs powered by Verizon 5G

## 1. はじめに

企業の PC にセルラー接続（5G）を加える意義を、Verizon Business の担当者と Microsoft Surface 事業の担当者が交互に話す、約 25 分のシアター形式のセッションです。ハイブリッドワークと AI の利用が広がり、常時接続の信頼性が以前より重要になっている、という問題意識から始まります。

前半は Microsoft 側から、Windows のセキュリティと管理に関する今回の発表内容です。後半は Verizon 側から、調査結果、導入手順、調達の考え方、試用プログラム、将来の方向性が説明されます。画面を使ったデモはありません。

> 注意：セッションのタイトルには「最大 50% の ROI」とありますが、50% という数値は発話では語られていません。語られた ROI の数値は、Forrester の調査にある 3 年間で 135% 超です（5.4 節）。

## 4. 発表者が伝えたいメッセージ

Marissa は、持ち帰ってほしい要点を 3 つにまとめています。

- **接続は単なる公共サービスではなく、競争上の強みである。** 従業員や顧客が必要な場所に姿を見せ、接続の心配なく仕事ができる。
- **ROI は測定できる。** Verizon Business と Surface は 10 年以上、Surface のセルラー対応で提携している。直近 2 年は AI 市場の進化で最大の変化があり、企業市場の **10% 超**がセルラー接続の調達を始めた。会場の人にも、その次の 1 ポイントになってほしいと述べた。

Richard は、Windows を次の時代の仕事に向けて作っていると述べ、5G の価値は、モバイル化による生産性向上という ROI と、安全な接続の維持の 2 つにあるとしました。

## 5. 発表内容の詳細

### 5.1 Microsoft の視点：なぜ今か

Richard は、この 1 年で、組織は「AI を使うべきか、どう使うべきか」という問いから、実際の展開に移ったと述べました。エージェントはアプリやファイル、システム、データベースをまたいで動いており、技術リーダーの議論は、**どう安全を確保し、封じ込め、コストとリスクが価値を上回らないように成果を拡大するか**に移っています。

脅威も加速しています。Microsoft Digital Defense Report では、AI の悪用や脆弱性の悪用が、かつては高度な専門技術だったものが、簡単なプロンプトで実行できるようになったと指摘されたそうです。Microsoft も AI を使っており、その例として MDash（Microsoft Multimodal Agentic Scanning Harness）が紹介されました。Microsoft のエコシステム全体の脆弱性を走査するもので、**10 月の 1 か月で 1,100 件の脆弱性**を見つけたと述べています。これは 2025 年全体の件数と同じです。検出が向上したことに加えて、脅威の量が増えているとも話しました。

### 5.2 Windows の新発表

Richard は、Ignite で前日に出た発表を中心に紹介しました。

**信頼できる基盤としての Windows**

| 項目 | 状況 | 説明 |
| --- | --- | --- |
| Windows Administrator protection | 一般提供開始 | 発話では詳細の説明はありません |
| Windows Baseline protection | プレビュー | セキュアブートや仮想化ベースのセキュリティなどの基盤的な保護を、1 つのバージョン付きの状態にまとめる。管理者は端末が準拠しているかを 1 つの画面で確認でき、ユーザーにも準拠状況が見える。保護を有効にするよう促す画面要素も表示される。IT は端末ごとに「はい／いいえ」の明確な答えを得られる |
| Windows Autopatch | 提供中 | Autopatch の顧客は、オンプレミスで管理する同種の組織より、**更新が 40% 速い**という数値が示された。自動パッチ適用で、再起動は月 1 回を目指している |

> 補足：Richard は再起動が月 1 回になることを期待していますが、月次レビューの 2 分前に再起動が起きないことまでは保証できない、と冗談を交えて述べています。

**エージェントに最も安全な基盤**

MXC（Microsoft Execution Containers）が紹介されました。エージェントを安全に封じ込めるための実行コンテナーで、Windows 向けに特化していますが、クラウドや Mac を含む全プラットフォームで使えるという説明です。OpenAI と Meta がすでにこの上で構築しており、Anthropic の Claude も採用を進めていると述べています。

**ハイブリッドなインテリジェンス**

Build で Satya 氏が話した「従量課金に縛られない知能」の考え方です。ローカルのモデルを使い、推論をローカルの計算資源とクラウドで組み合わせて、AI コストの急増を抑えます。

**PC から Azure までの 1 つの資産**

Windows 365 の Direct Stream、公開プレビューの Windows Server 2028、Microsoft Foundry などが挙げられ、PC からクラウドまでを 1 つのプラットフォームとして扱えると説明しています。

**セキュリティエージェントの動作位置の変更**

長い間、セキュリティエージェントはカーネルのレベルで動いていました。Richard は、Bitdefender、CrowdStrike、SentinelOne など大手の各社と協力し、これをカーネルではなくユーザーのレベルで動かす取り組みを進めていると述べました。10 年ほどかかった変更だそうです。

これらは Intune と Autopilot による最新の管理・展開の一部であり、Verizon 5G による移動型の働き方の ROI を考える土台だという位置づけです。

### 5.3 現場の課題：接続の問題

Marissa は、ここまでの話はソフトウェアと OS のセキュリティの話で、セルラー接続を加えるとさらに利点があると続けました。例えば、最新の更新やパッチのダウンロードは、端末がインターネットに接続できる場合にだけ可能です。セルラーなら、Wi-Fi の有無や場所に関係なく端末に届きます。

現場の担当者は、顧客先、空港、カフェなどで働きます。スマートフォンのテザリングを使い切ったり、企業のセキュリティ方針に反する公共 Wi-Fi に接続したり、接続を待ったりしています。Marissa は、これは Wi-Fi の問題ではなく**接続の設計の問題**だと述べました。

### 5.4 調査結果

| 調査 | 結果 |
| --- | --- |
| Omdia（Verizon が委託） | 企業リーダーの **95%** が、オフィス外（自宅や外出先）の接続のセキュリティを懸念している |
| Omdia | ほぼ半数の回答者が、保護されていない公共ネットワークでのデータ漏えいを、AI が加える最大の脅威として挙げた。ほかのどのリスクの 2 倍以上 |
| 調査（出典の明示は発話では確認できません） | ユーザーは、接続するだけで年平均 **22 時間**の生産時間を失っている |
| Forrester（Verizon が委託。複合モデル） | 売上約 5 億ドル、2,000 ユーザー（うち 400 人がモバイルの営業担当）の企業を想定。5G への切り替えで **3 年間で 135% 超の ROI、6 か月で回収**。失われていた時間を取り戻し、運用の生産性が **34%** 向上する |

Forrester の結果を受けて、売上の増加にもつながるという発言がありました。さらに、**ゼロタッチ プロビジョニングによる展開時間の 25% 短縮**という数値にも触れられています。話者も、どの調査の数値かも、発話では明示されていません。

最新の展開方式では Intune による展開を 5G 経由でできるとも説明されています（話者は発話では明確に確認できません）。安全で信頼できる接続がない遠隔地の従業員にも、端末を送り、Verizon 5G で Intune に登録できます。

### 5.5 導入の進め方

**1. ネットワークの選択と方針を決める**

Intune を使って、端末が接続できるネットワークの種類を制限できます。例えば、社内ではオンプレミスの Wi-Fi、外出時は公共 Wi-Fi に接続させずセルラーだけを許可する、という方針です。セキュリティと IT 管理の両面で利点があるとのことです。

**2. 調達**

- セルラーの機能は、購入時に構成しておく必要がある。Microsoft などのパートナーには、セルラーモデムを内蔵した別の SKU がある。
- Wi-Fi 専用機よりは少し高いが、Apple、Samsung、Google のセルラー対応タブレットと同程度の価格差である。
- 全員に一斉に導入する必要はない。適した用途の利用者から段階的に始める。例として、現場担当者、保険の損害査定担当者、金融・保険業界、公共部門（警察官の頑丈な PC）が挙げられた。
- 今は必要がなくても、調達計画に **5G の枠を確保**しておく。後から付け足さず、IT 戦略の早い段階で組み込み、Intune や eSIM の扱いを担当者が把握しておく。

**3. 管理と有効化（eSIM）**

Verizon のネットワークで承認されている最新の PC は、**100% が eSIM に対応**しています。端末に触れずに Intune とデジタルの有効化の流れで遠隔展開でき、物理 SIM を抜いて他に使うこともできないため安全になるという説明です。登壇者の 1 人（話者は発話では確認できません）は、物理 SIM の挿入では IT 担当者が苦労するが、eSIM なら梱包された端末を開けずにユーザーへ発送でき、IT 部門の大幅な時間短縮と ROI になると述べました。

**4. 料金と意思決定**

Marissa は、スマートフォンは事業部門が調達・有効化・予算を担うことが多いが、PC は IT 部門がハードウェアの調達と契約を担い、月額のサービスプランは事業部門が負担する、という違いを指摘しました。プランはハードウェアに含まれません。Verizon の標準では、**ビジネス向けの無制限データが月 20 ドルから**です。そのため共同の意思決定になり、事業部門のリーダーに、適した用途と優先順位を尋ねてほしいと述べています。

### 5.6 試用プログラム

最近始まったデモプログラムでは、Microsoft の法人営業担当、または流通パートナーの TD SYNNEX を通じて、Verizon 5G 対応の Surface のパイロット用デモ機を、**最大 90 日間無料**で試せます。

Richard は、無料試用すると、おそらく 5G を採用することになると、半分冗談で述べました。5G を使ったことがなかった Surface 事業部の同僚に展開したところ、1 か月後に、VP から「なぜ全員が 5G を使わないのか」と聞かれたそうです。スマートフォンで手動のネットワーク切り替えは想像できないのと同じく、一度使うと元には戻れない、という感想です。

Marissa は、自分の画面右下で、会場で 5G に接続していることが見えると話しました。会場でパスワードを聞かず、公共 Wi-Fi の帯域を取り合わず、VPN に接続しなくても、ツールを使えるという実感です。

### 5.7 今後の方向性

以下は将来の計画に関する発言で、現在提供済みの機能ではありません。

- **ネットワークスライシング**：現在は、公共安全の利用者向けの Verizon Frontline スライシング技術が中心。重要な利用者に専用の車線を提供する（ハイウェイの優先車線のたとえ）。企業向けのスライシングの展開も始めており、Intune のような MDM で監視・管理する想定。重要なアプリは専用の車線で止まらず動かし、メールなどの日常の通信は通常の回線に残す。
- **衛星**：次に来る接続の規格として、Verizon が戦略を開発中。PC では、どこでも働ける次の層になる。Richard は、通信業界でいう非地上系ネットワーク（NTN）にも触れた。
- **管理プラットフォーム**：端末の有効化と管理をさらに簡単にするための新しい提携を進めている。Marissa は、来年の後半に具体的な内容を伝えると述べた。

Richard は最後に、3〜5 年後には広帯域、衛星、5G、Wi-Fi の状況が大きく変わると述べ、今日の 5G 導入で即時の ROI が得られるとともに、IT 資産の近代化を今から進めて次の変化に備えるよう呼びかけました。

## 6. デモ・手順

このセッションでは画面を使ったデモは行われていません。スライドと口頭の説明が中心です。画面のスクリーンショット（Windows Baseline protection の新しい画面要素）への言及はありますが、操作の実演はありません。

導入の手順として、次の流れが語られました。

1. ネットワークの選択とポリシー（Intune で接続先を制限）を決める
2. セルラーモデム内蔵の SKU を、適した利用者向けに購入時に構成する（調達計画に 5G の枠を確保する）
3. eSIM と Intune で、端末を開封せずに遠隔で有効化・展開する
4. 月額のサービスプラン（無制限データは月 20 ドルから）は、事業部門と共同で判断する

## 7. 注意点・発表者の気付き

- セルラーの機能は、購入時に構成が必要です。後から追加する想定ではありません。
- セルラー対応モデルの価格は少し上がりますが、他社のセルラー対応タブレットと同程度の差です。
- PC の月額プランは、ハードウェアには含まれません。IT と事業部門の共同の判断が必要です。
- 試用プログラムでは、トライアルの後に 5G を採用する可能性が高いと、発表者自身が話しています。
- 数値の出典（Omdia、Forrester）は Verizon が委託した調査です。ゼロタッチの 25% の出典は発話では確認できません。

## 8. 利用者にとっての利点

- 場所や Wi-Fi の有無に関係なく、更新・パッチ・業務ツールに接続できる。
- 保護されていない公共ネットワークの利用を避けられ、データ漏えいのリスクを下げられる。
- Forrester の複合モデルで、3 年間の ROI は 135% 超、回収期間は 6 か月、運用の生産性は 34% 向上。
- eSIM とゼロタッチによる遠隔展開で、IT の手間を減らせる。
- 既存の Intune 管理や機種構成を変えずに、適した利用者から段階的に導入できる。
- 最大 90 日間の無料試用で、事前に確認できる。

## 9. まとめ

発表は、AI の利用が広がる今、場所を問わず安全に接続できることが PC の価値を左右するという主張でした。Microsoft 側は、Windows の Baseline protection、Autopatch、MXC などの安全な基盤を示し、Verizon 側は、5G の ROI の調査結果と、eSIM、Intune、調達の進め方、月 20 ドルからの料金、90 日の試用を説明しました。将来はネットワークスライシングと衛星が計画されています。問い合わせ先は verizon.com の laptops のページと、laptops 宛てのメールアドレスです。
