# BRK229 Frontier Accelerate: Microsoft benefits that help you move forward

## 1. はじめに

このセッションは、Microsoft が顧客とパートナー向けに用意した特典パッケージ **Frontier Accelerate** の全体像を紹介する 45 分のブレークアウトセッションです。「専門家へのアクセス」「投資・コスト面の支援」「スキル習得」の 3 本柱で構成され、Azure、Copilot、Dynamics 365、Microsoft 365、セキュリティ、Marketplace など Microsoft の幅広い領域を対象にしています。

セッションでは、パッケージの全体像、Ignite で発表された 2 つの具体例（Azure Catalyst と AI Flex plan）、そして Telefonica Germany の導入事例が順に語られます。AI の取り組みで「どこから始めるか」を考えている方が、Microsoft にどう相談すればよいかを整理する内容です。画面を使ったデモはなく、2 本の動画の上映があります。

## 5. 発表内容の詳細

### 5.1 Frontier Accelerate とは

紹介動画では、Frontier Accelerate は **「簡素化された Microsoft の特典パッケージ」** で、Microsoft の信頼できる専門家、投資面の特典、スケーリングのための支援を束ねたものと説明されています。動画が挙げた 3 つの切り口は次のとおりです。

- 変革のビジョンを実現したい：Microsoft のスペシャリストと、認定されたパートナーが計画と構築を支援する
- 投資からより多くの価値を得たい：利用可能な価格オファー、資金面のリソース、節約の機会を確認できる
- チームに新しい技術を使いこなしてほしい：セルフペース学習、専門家による研修、ハンズオンラボで、組織の力を高める

動画の後、登壇者は、特典が Microsoft の幅広い領域にまたがると補足しました。スライドに示された領域は、Azure（Azure のデータベースを含む）、Copilot、Dynamics 365 による業務プロセス、「AR ready」と聞こえる生産性（文脈上は Microsoft 365 の中核を指しますが、音声認識の都合で表記が確定できません）、より高度なセキュリティです。さらに、Marketplace への登録を進めるパートナーやソフトウェア企業向けに **Frontier Accelerate for Marketplace** も用意されています。利用を始めるには、動画の案内どおり、Microsoft のアカウントチームか認定パートナーに連絡します。

### 5.2 3 本柱の詳細

登壇者は「写真を 1 枚だけ撮るならこのスライド」として、パッケージ全体を示す 1 枚を紹介しました。ここには多くの機能とリソースがあり、次のように整理されます。

| 柱 | 内容 |
|---|---|
| 専門知識（trusted expertise） | **アセスメントとツール**、Microsoft の社員による支援、専門パートナー |
| 投資と節約（savings and investments） | 価格オファー、パートナー経由の資金、価格・節約プラン |
| スキル習得（skilling） | Microsoft Learn によるセルフペース教材、ライブセッション、エンタープライズ向けスキル習得イニシアチブ |

**専門知識**

- **アセスメントとツール**：Copilot の評価や、オンプレミスの状態をクラウドへ移行するためのアセスメントなど、ワークロードごとのツールが、顧客が自分で使える（セルフサービス）形でも、パートナー経由でも提供される
- **Microsoft の社員による支援**：**FastTrack for Microsoft 365** と **Cloud Accelerate Factory**。どちらも顧客が無料で使えるリソースで、生産性クラウド、またはインフラとデータベースのクラウドへのオンボードを支援する（どちらがどちらを担当するかは、発話では区別されていません）。FastTrack は以前からあり、Cloud Accelerate Factory はこの 2 年で大きく成熟したと説明している
- **専門パートナー**：登壇者は「地球上で最大のパートナーエコシステム」と述べ、前述の各領域に対応した専門性を持つパートナーがいるとしている

**投資と節約**

- サービスを追加するときの価格オファーがある
- 適切な専門パートナーと組めば、パートナーが Microsoft から投資・資金提供を受け、プロジェクトに充当できる。金額は地域、機能、ワークロードによって異なる
- Microsoft のサービスを拡大するにつれて使える、価格・節約プランがある

**スキル習得**

開発者、実務担当者、エンドユーザーまでを対象に、Microsoft Learn を通じて提供されます。セルフペースのオンライン教材、ライブセッション、そして非常に大規模で複雑な要件をもつ顧客向けの enterprise skilling initiative があります。

### 5.3 例 1：Azure Catalyst

専門知識とツールの例として、Ignite 初日に発表された **Azure Catalyst** が紹介されました。クラウドへのモダナイゼーションを支援する、新しい統合サービスです。説明された内容は次のとおりです。

1. オンプレミスの状態を評価する（assessment）
2. ビジネスケースの作成を支援する
3. 必要なモダナイゼーションを特定し、実際の作業も支援する
4. コードのモダナイズには GitHub Copilot を起動して使う。たとえばオンプレミスで VB6 アプリケーションが動いている場合、クラウドに移植・実装できる状態になるよう、GitHub Copilot が VB のコードをモダナイズする
5. データベースとインフラのモダナイゼーションも同様に支援する
6. 進捗をダッシュボードで確認できる

IT 担当者は、進行の速さや、切り替え（カットオーバー）をいつ行うかを判断します。すべては IT と連携して進めるものと説明されています。顧客のフィードバックに基づいて作られた、**セルフサービスで使える強力なツール**で、他のツール同様にエージェントベースです。

登壇者によると、半年前はコード行数が多すぎる、データベースやインフラが複雑すぎるといった理由で、ビジネスケースが成り立たない顧客もいました。Azure Catalyst とエージェントにより、重労働の大部分が自動化されるため、顧客は**ビジネスケースを作り直し、モダナイズの機会を再分析している**そうです。

### 5.4 例 2：AI Flex plan

投資と節約の例として、顧客のフィードバックから作られた新しいプラン **AI Flex plan** が紹介されました。Microsoft IQ、Copilot と Cowork、Foundry、GitHub を使っている顧客が、IT、エンドユーザー、開発者の別を問わず、Microsoft の容量を 1 か所でまとめて購入し、一元的に消費（draw down）したいという要望に応えるものです。登壇者は「これまでこうしたものはなかった」と述べています。

| 項目 | 説明された内容 |
|---|---|
| 位置づけ | 単一の AI ポートフォリオへの投資。消費の仕方に柔軟性がある |
| 消費の仕方 | GitHub と開発者のみ、Cowork のみ、共有環境など |
| 購入サイズ | 複数のサイズ・容量から選べる |
| 契約期間 | 1 年または 3 年 |
| 支払い | 月払いまたは前払い |
| Azure commitment | Azure commitment（登壇者は Microsoft Azure commitment の愛称として "Mac" と呼んでいます）を持つ顧客は、AI Flex plan を接続して、その commitment から消費できる。**commitment がなくても利用できる** |
| 対象サービス | Microsoft の AI サービスが対象。一部だけ使っている場合でも、将来使うようになった場合でも対象になる。すべてを使う必要はない |

登壇者は、発表から 1〜2 週間しか経っていないプランで、顧客とパートナーからのフィードバックは良好だと述べ、今後もフィードバックに基づいて改善していくとしています。

### 5.5 Telefonica Germany の事例

ここから Gaelle 氏に交代しました。どの顧客の旅もどこかから始まる、という導入のあと、Telefonica Germany の事例が紹介されました。同社の旅は、信頼とデータの保護から始まったとのことです。

**背景**

- Telefonica Germany は、ドイツの 4 つの携帯電話事業者の 1 つ
- 課題は、スケールしながら顧客データを保護すること。これは必須要件だった
- Copilot でスケールするための安全な基盤が必要で、いずれはエージェント基盤へ移行したいと考えていた

**動画（Telefonica の担当者のコメント）**

動画の話者の氏名は文面から分かりません。内容は次のとおりです。

- フランチャイズと間接販売のパートナー、**約 13,000 のオペレーター**を通じて販売している
- パートナーは自分のハードウェアで作業するが、扱うのは銀行口座や住所を含む顧客の機微なデータである。「応急処置（duct tape）」で済ませることもできたが、構造的な解決を求めた
- 代替案は、完全な仮想マシンを渡してブラウザーを起動させる方法か、アプリケーションだけを公開（publish）する方法で、後者を選んだ。ネイティブのように見え、パートナーのデバイスで動き、より安全である
- ハードウェアとソフトウェアを分離し、**どの PC のハードディスクにも顧客データを置かない**
- 3 層構成：Entra ID（MFA、passkey などの標準機能）、公開したアプリ（その背後に自社の Web アプリケーション）、そして DLP、Purview、条件付きアクセス（動画の音声からは構成の細部まで確定できません）。業務に必要なデータにはアクセスさせ、許可されないデータの持ち出しはブロックする
- 最初の 2 週間で 3,000 ユーザー、フル展開も予定どおり完了
- 運用コストは **90% 削減**、プロビジョニングは **80% 削減**、**13,000 ユーザー**が稼働
- 「信頼が何よりも確保された」「Microsoft との協力で実現でき、今はあらゆることが可能だと考えている」

**Raid 氏へのインタビュー**

続いて、Telefonica Germany の technical lead and solution architect である Raid 氏が登壇しました。Gaelle 氏の質問に対する回答の要旨は次のとおりです。

1. **役割と課題**：Raid 氏の主な担当はワークプレースと変革。間接パートナー（フランチャイズや間接販売店）が自分のハードウェアと現地の管理者を使いながら、最も機微なデータを扱っていることが課題だった
2. **Windows 365 の導入**：Gaelle 氏が「Windows 365 をソリューションとして検討していたと聞いたが、環境が複雑で大きなプロジェクトに見える」と尋ねたのに対し、Raid 氏は、**政府の厳格な要件により、13,000 人に対して 90 日しかなかった**と説明した。厳しい期限のため、すでにこの種の問題を解いた専門家と時間が必要で、Microsoft が提供する専門家が助けになった。一般的な回答ではなく、実際の環境で手を動かして支援してくれる人が必要だったという（この部分は音声が不明瞭で、他社との比較かどうかは確定できません）
3. **コスト**：コストは今、どの会社でも以前より重要で、13,000 ユーザーのプロジェクトは最初からうまくいく必要があった。Microsoft はライセンス面で魅力的な商用提案をし、移行にも役立った。パートナーがバウチャー（vouchers）を受け取れるため、プロジェクトのコストが下がり、より速く進められた
4. **Copilot の定着**：Raid 氏は、ソリューションを導入するなら、実際に使われることを確認する必要があり、導入支援（adoption）が最も重要だと述べた。Microsoft とパートナーの **Wipro** が、日常業務での Copilot の使い方をユーザーに示した。ライセンスを渡すだけでなく、仕事が楽になる具体例を示し、それを繰り返して大きな成果につなげる。この支援はドイツ語でも英語でも行われた
5. **ドイツの workers' council（労使協議会）**：ドイツには workers' council があり、承認なしにはアプリケーションを導入できない。ドイツには Microsoft の拠点にも workers' council があり、Microsoft が自社の労使協議会をどう説得したかという経験を共有してくれたことで、承認を得られ、展開できた
6. **成果と誇れる点**：最も誇れるのは**「信頼」**。パートナー側のハードウェアにデータが残らないため安全である。ほかに、運用コスト 90% 削減（経営層も喜ぶ）、**80% 高速化**（ユーザーのデバイスが速くなる。トランスクリプトでは "Industry 65" と聞こえますが、文脈から Windows 365 の意味と思われます）、**13,000 人が 19 日で期限どおり稼働**したこと。これが、将来さらに大きなことに挑戦する自信にもなった
7. **聞き手への助言**：**課題から始め、ソリューションや技術から始めない**。必要なものを、セキュリティやユーザー体験の観点から考える。そのうえで Microsoft のサポートを受けながら、適切な人と専門知識を集める。そうすれば何でも実現できる

> 補足：動画では「80% reduction in provisioning」、インタビューでは「80% faster」と、表現が異なります。トランスクリプトの語のまま記載しています。

### 5.6 3 本柱での相談と、利用の始め方

Gaelle 氏は、Raid 氏が課題を見つけ、必要なもの（人、オファー、構造）を考えた流れを引き、枠組みを簡素化して示しました。

1. **専門知識**：取り組むプロジェクトの種類に応じて、何らかの形で必要になる
2. **投資と節約**：提案やディール、プロジェクトをどう組み立てるかの支援
3. **スキル習得**：「ループを閉じる」要素。エンドユーザーや IT が実際に使えるようにすること

登壇者は、Microsoft の担当役員やパートナーに対して「この 3 本柱でどう支援してもらえるか」と話せば、支援を得られるはずだと述べています。プログラムとオファーは **50 以上**あり、Microsoft のソリューション全体（コアから AI まで）にまたがります。特典の一覧（brochure）を見て、幅広さを確認することを勧めており、その理由として、存在を知らないものが多いだろうからだと説明しています。QR コードをスキャンすれば詳細に進め、ブースと「Frontier Accelerate newsstand」でも対応するとのことです。

## 8. 利用者にとっての利点

発表で語られた利点は次のとおりです。

- 専門知識・投資・スキル習得の 3 点を 1 つのパッケージとして相談できる。50 以上のプログラムとオファーが、Microsoft のソリューション全体にまたがる
- FastTrack for Microsoft 365 と Cloud Accelerate Factory を無料で使える
- 適切な専門パートナーを通じて、Microsoft からの資金支援を受けられる場合がある
- Azure Catalyst により、以前は成立しなかったモダナイゼーションのビジネスケースを再検討できる
- AI Flex plan により、Microsoft IQ、Copilot と Cowork、Foundry、GitHub にまたがる AI の購入と消費を 1 つのプランにまとめられる
- Telefonica Germany の成果：13,000 人を 19 日で稼働、運用コスト 90% 削減、プロビジョニング 80% 削減（または 80% 高速化）、パートナー側のハードウェアに顧客データを残さない構成

## 9. まとめ

Frontier Accelerate は、Microsoft が過去 2 年の取り組みを 1 つにまとめた特典パッケージで、**専門知識、投資と節約、スキル習得**の 3 本柱で構成されます。Azure から Copilot、Dynamics 365、セキュリティ、Marketplace まで幅広い領域を対象にし、FastTrack for Microsoft 365 や Cloud Accelerate Factory の無料支援、パートナー経由の資金、Microsoft Learn によるスキル習得などを含みます。

具体例として、モダナイゼーションを支援する Azure Catalyst と、複数の AI サービスを 1 つで購入・消費できる AI Flex plan が紹介されました。Telefonica Germany は、90 日という期限のもと Windows 365 の導入に取り組み、13,000 ユーザーを 19 日で稼働させ、運用コストを 90% 削減しました。登壇者が勧めるのは、課題から始め、3 本柱について Microsoft の担当者やパートナーに相談することです。
