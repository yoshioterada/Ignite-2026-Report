## 3. 何に関する発表か（公式の概要）

セッションの種別は Breakout（45 分）、カテゴリは Windows です。公式の概要は次のとおりです（原文の趣旨を日本語にしたものです）。

> GitHub Copilot on Windows が、ローカルの AI とクラウドの AI を組み合わせて、コーディングの作業ごとに適した計算リソースを割り当てる様子を紹介します。MAI Code 1.1 Flash を、個人の PC から、DGX Station for Windows でのチーム規模の推論まで取り上げ、IT 部門向けの管理機能（IT controls）と利用状況の分析（usage insights）にも触れます。

原文（英語）：

> See how GitHub Copilot on Windows combines local and cloud AI to match each coding task with the right compute. Explore MAI Code 1.1 Flash from individual PCs to team-scale inference on DGX Station for Windows, with IT controls and usage insights.
