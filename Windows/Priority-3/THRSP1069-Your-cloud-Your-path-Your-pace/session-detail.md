# THRSP1069 Your cloud. Your path. Your pace.

## 1. はじめに

このセッションは、デスクトップ仮想化（EUC：エンドユーザーコンピューティング）の環境をクラウドへ移していくときに、「いまどこにいて、どの選択肢があり、どう動けばよいか」を整理する約 20 分の発表です。話し手は Nerdio の Scott Manchester 氏で、Microsoft の Windows クラウド製品（Azure Virtual Desktop、Windows 365）を軸に、次の 3 つを順に紹介します。

- 現在の仮想化環境を評価する無料ツール **Nerdio Compass**（パブリックプレビュー）
- オンプレミスの VM を Azure Virtual Desktop（AVD）で管理できる **AVD Hybrid**（一般提供。vSphere 対応は Nerdio Manager でパブリックプレビュー）と、それを Nerdio Manager で扱う方法
- 移行を「一度きりの作業」にせず、評価と見直しを繰り返すという考え方

発表中には、Compass の動作を示すデモ（発話上は短い動画）と、vSphere 環境への AVD Hybrid 適用を示すデモの 2 本があります。

登壇者は「飛行機を作りながら飛ばす（fly the plane while you're building it）」という表現を 2 回使い、稼働時間（アップタイム）を保ったまま移行することを重視していると繰り返しています。

## 5. 発表内容の詳細

### 5.1 調査結果：移行は 2 年で加速する

Nerdio が第三者機関に委託した調査では、Scott 氏の説明によると、**175 社のエンタープライズ顧客**（複数の業種・地域）に、クラウド移行の現状と阻害要因を聞いています。主な数値は次のとおりです。

| 項目 | 内容 |
| --- | --- |
| 調査対象 | エンタープライズ 175 社 |
| すでに仮想化環境がハイブリッド状態の組織 | 46%（2 社に 1 社。複数の仮想化ソリューションを併用している場合も多いと説明） |
| 最新のクラウドインフラが利用可能になってからの 10 年間 | 11%（最初に「23%」と言い、「11%」と訂正） |
| 今後 2 年間 | 23% |

登壇者は、これを「10 年分の移行を 2 年に圧縮する」状況だと表現しています。

> 注意：11% と 23% が何の割合かは、発話では明示されていません（移行の進み具合を指していると読めますが、発表では定義まで述べていません）。

AI などで変化が速くなるなか、従業員に効率的なツールを使わせ、高いセキュリティと SLA を維持するには、素早く適応する必要があるというのが背景です。この調査は「The Great EUC Migration」というレポートにまとめられており、Nerdio のサイトや Scott 氏の LinkedIn で共有されていると案内されました。

### 5.2 選択肢の多さと判断要素

仮想化環境の構築方法は多く、選び方がコスト、効率、アップタイム、エンドユーザー体験に大きく影響する、と説明されます。挙げられた構成要素と判断要素は次のとおりです。

- デプロイ形態：共有デスクトップ、シングルセッション、AVD のリモートアプリ、Windows 365 経由のクラウドアプリ
- アプリの構成：多層アプリで、データベースなど一部のリソースはオンプレミスに残し、残りをクラウドへ移すケース
- ユーザーの種類：フロントラインワーカー、営業担当、契約社員、BYOD か会社支給か
- 組織の要件：セキュリティ・コンプライアンス、社内ポリシーによる移行の制限
- 既存投資：Citrix ライセンスを更新したばかりか、データセンター用ハードウェアを買ったばかりか、リースの満了が近いか
- 現実的なタイムライン

### 5.3 Nerdio Compass（無料のアセスメントツール）

Compass は、NerdioCon（今年 5 月）で発表されたツールで、今回「再発表」されました。Azure Marketplace で無料提供されており、現在は**パブリックプレビュー**です。仮想化環境の現在の投資状況を評価することに焦点を当てています。

対応範囲は次のように説明されています。

- 現在利用可能：Microsoft 環境のアセスメントと、Citrix Virtual Apps and Desktops（CVAD）および Citrix Cloud の投資状況の評価
- 今後の拡張：AWS 環境、Omnissa 環境、Citrix CVAD と Citrix DaaS（発話では "Citrix DAS" と聞こえます）、Microsoft 環境全体へと対応を広げていく。発表の最後では、CVAD または Citrix DaaS の利用者は今すぐ使え、Omnissa、Amazon WorkSpaces、Remote Desktop Services 向けの機能は「近日対応」と案内されています。

ツールが出力するものとして、次の 3 つが挙げられました。

1. **作業範囲書（Statement of Work）**：社内 IT 部門、または SI パートナーや外部委託先と進めるときに、移行の作業内容を詳細に示す。価格や移行の負担コストの交渉に使える。
2. **Microsoft ライセンスの一覧**：Microsoft へ移行する際に必要なものを一覧にし、Microsoft との交渉に使える。
3. **移行計画**：Nerdio Manager を使っている（または検討している）場合、推奨された移行を進める際にこの出力を使える。

データは利用者自身が管理し、環境のスナップショットを JSON ファイルとしてインポートする方式です。

### 5.4 コスト比較と継続的な評価

デモ画面の数値は、Citrix から Windows クラウド製品へ移行した場合のコスト削減の実例として示され、ライセンス期間を通じて**数万ドルから数十万ドル**の削減になると説明されました。Windows クラウドには AVD、AVD Hybrid、Windows 365 Enterprise、Windows 365 Flex Dedicated、Windows 365 Flex Shared といったデプロイモデルがあり、どれを選ぶかでコストとユーザー体験が大きく変わります。Scott 氏は、昨年の Ignite に Microsoft の社員として登壇し、Flex Dedicated と Flex Shared を Windows 365 の新しい選択肢（Cloud Apps を含む）として発表したと振り返っています。

さらに、今日の最適解が明日も最適とは限りません。部署の移転、働き方の変化、使うアプリやサービスの変化、オンプレミスの基幹業務アプリのクラウド移行などが、仮想化投資の経済性に影響します。そこで、**Nerdio Visor**（聞こえたままの表記で、音声認識の都合で名称が確定できません）が常時動いて環境を評価し、より低コストで良い体験を提供できる方法を提案する、と登壇者は説明しています。「一度で終わる作業ではなく、変化と評価の無限ループだ」というのが登壇者の言い方です。

### 5.5 AVD Hybrid と Nerdio Manager

Microsoft が前回の Ignite から今回の Ignite の間に発表した **AVD Hybrid** が紹介されました。AVD の管理プレーン（Azure 上でホストされる）を使って、Azure 上のリソースだけでなく、オンプレミスのリソースも管理できます。

登壇者は、この決定を 3、4 年前に Microsoft で始めたと述べ、完了までに時間がかかったと話しています。その際の方針は、「Microsoft がライフサイクル管理機能をすべて作るのではなく、その部分はパートナーに任せる」というものでした。仕組みは次のとおりです。

- VM を作成する既存インフラ（Nutanix、vSphere などの一般的なハイパーバイザー）はそのまま使う。
- AVD がその上の管理レイヤーを提供する。各 VM を Azure Arc に登録し、AVD サービスへの接続に必要なエージェントを追加し、ホストプールに登録する。
- Nerdio が、VDI インフラとハイパーバイザーのあいだの「つなぎ（connective tissue）」を提供する。これにより、クラウドとオンプレミスのリソースを Nerdio Manager という 1 つの管理ソリューションで、コスト効率よく扱える。

提供状況は次のとおりです。

| 対象 | 状況（発表での説明） |
| --- | --- |
| AVD Hybrid | 発表の時点で一般提供（"generally available today"）。今日から使える |
| Nutanix | AVD Hybrid を最初にサポートしたゴー・トゥ・マーケットのパートナー。会場にブースがあり、動作デモを行っている |
| vSphere（Nerdio Manager での対応） | パブリックプレビュー。この日発表した最新の対応 |

### 5.6 クラウドへの移行機能

ワークロードをクラウドへ移す段階になったら、Nerdio Manager の**移行機能**で、オンプレミスのワークロードをクラウドへ「シームレスに」移せると説明されています。1 ユーザーずつ移すことも、実施時間をスケジュールすることも、一括で移すこともできます。

### 5.7 市場での評価

Scott 氏は、Gartner の「Magic Quadrant for Desktop as a Service」で Microsoft が 3、4 年にわたりリーダーであり、他の競合を上回るペースでイノベーションを続けていると述べています。IDC の「IDC MarketScape for DaaS」でも同様に Microsoft が先行している、という説明です。そのうえで、Nerdio はこれら Microsoft のソリューションをつなぎ、大規模に管理するためのツールだと位置づけています。Microsoft が AVD Hybrid や新しい Windows 365 のライセンスモデルなどの新機能を出すたびに、Nerdio のツールがユーザーの現在の使い方を評価し、移行した場合のコスト削減や体験向上を見つけると説明しています。

## 6. デモ・手順

このセッションにはデモが 2 本あります。1 本目の Compass は、発話で「quick video（短い動画）」と述べられており、途中で一時停止して補足する場面があります。時間が短いため、ツールの出力の一部（作業範囲書など）は動画には含まれないと断っています。2 本目の vSphere のデモが動画かライブかは、発話からは分かりません。画面の細部は音声からは確認できないため、語られた範囲だけを書きます。

### 6.1 Nerdio Compass のデモ

1. まず、Microsoft 環境の可視化の例を示す。デモ用の小規模な顧客環境で、スナップショットのインポートにより読み込む。登壇者は自分の Microsoft 環境をインポートしたと話している。
2. 画面には 20 ユーザーと、いくつかのデプロイ構成が表示される。この顧客は Windows 365 のライセンスを 1 つだけ持っており、「Windows 365 を試している段階」だと説明された。
3. 次に Citrix への接続を説明する。接続方法は 2 通りある。
   - **CVAD または Citrix DaaS を使っている場合**：Compass の画面からダウンロードできるツールをオンプレミスで実行する。Compass 自体はクラウドで動き、CVAD 環境はオンプレミス（クラウドから隔離されている場合もある）にあるため。ツールは Citrix 環境に対して読み取り専用の操作を行い、デプロイモデルの詳細を JSON ファイルとして出力する。これを Compass にインポートする。
   - **Citrix のクラウドサービス（発話では "Citrix StaaS"）を使っている場合**：クラウドに直接接続でき、環境を継続的に可視化できる。
4. デモの顧客は、エクスポートツールをダウンロードして実行する。見た目は GUI だが、裏側は PowerShell だと説明された。
5. すぐに Citrix 環境の評価が始まり、Windows クラウド環境への対応づけ（AVD、AVD Hybrid、Windows 365 Enterprise、Windows 365 Flex Dedicated、Windows 365 Flex Shared）の推奨が示される。
6. コスト削減額の画面が示される（5.4 のとおり、数万〜数十万ドル規模の実例と説明）。結果は Nerdio Manager にエクスポートして移行に使える。
7. Citrix 側に設定されたポリシー（リダイレクトポリシーなど）やセッションカタログが、AVD や Windows 365 のどこに対応するかを対応づけて示す。登壇者は、VM を Citrix から Windows クラウドへ移しても「すべてそのまま動き続ける」ことを狙った機能だと説明している。

### 6.2 vSphere での AVD Hybrid のデモ（Nerdio Manager）

登壇者は、Nutanix と vSphere の体験は似ているが、最新の発表である vSphere で見せる、と前置きしています。

1. vCenter が引き続きイメージの作成を管理する。Nerdio Manager で、いくつかのパラメータを入力して vSphere 環境に接続し、OK をクリックする。
2. vSphere 環境を、各 VM を Arc エージェントに登録するように構成する。これには AVD エージェントの作成とホストプール登録の詳細も含まれる。
3. ホストプールをプロビジョニングする手順は、クラウドに作る場合も、オンプレミスのハイパーバイザー上に作る場合も**まったく同じ**。
4. イメージ選択の画面には、vSphere 上にあるイメージが表示される。イメージは vCenter 上で直接クローンされ、クラウドへ移す必要はない。
5. プール内の各 VM の作成中に、次の 3 つの自動化アクションが実行される。ログファイルでも確認できる。
   1. Arc エージェントのインストールと登録
   2. AVD エージェントのインストール
   3. AVD エージェントによるホストプールへの登録
6. VM が作成されたら、他のリソースと同様に Windows アプリで接続する。画面では Mac と Windows デバイスからの接続例が示され、クラウドと同じ体験がオンプレミスで得られると説明された。

## 7. 注意点・発表者の気付き

- **11% と 23% の意味**は、発表内で定義されていません（5.1 の注意を参照）。
- 「Nerdio Visor」という名称は、音声認識の都合で確定できません。
- Compass のサポート範囲は、現時点では Microsoft 環境と Citrix（CVAD、Citrix Cloud）です。AWS、Omnissa、Amazon WorkSpaces、RDS は「今後対応」と説明されています。
- Compass のデータは利用者が管理し、JSON のインポートで読み込みます。CVAD 環境向けのエクスポートツールは読み取り専用の操作です。
- AVD Hybrid は一般提供ですが、Nerdio Manager での vSphere 対応はパブリックプレビューです。
- AVD Hybrid では、Microsoft はライフサイクル管理機能を自社で作らずパートナーに任せる方針を取りました。その部分を Nerdio Manager が担う、という位置づけです。
- Citrix ライセンスの更新が近い人には、更新前に Compass でアセスメントし、移行の機会を検討することが勧められました。

## 8. 利用者にとっての利点

発表で語られた利点は次のとおりです。

- 現状の可視化：Compass で現在の仮想化環境と Windows クラウドの各モデルへの対応づけを、無料で確認できる。
- コスト面：Citrix から Windows クラウドへ移行した実例で、ライセンス期間を通じて数万〜数十万ドルの削減が示された。
- 交渉材料：Compass が作業範囲書と Microsoft ライセンス一覧を出力するため、パートナーや Microsoft との交渉に使える。
- 既存投資の活用：AVD Hybrid では、Nutanix や vSphere などのハイパーバイザーとイメージ（vCenter 上でクローン）を、そのまま使える。
- 管理の一元化：クラウドとオンプレミスのリソースを、Nerdio Manager 1 つで管理できる。
- 稼働を保った移行：ユーザー単位、スケジュール、一括の移行に対応し、「飛行機を作りながら飛ばす」形で稼働を保てる。

## 9. まとめ

登壇者は、移行を次の 3 ステップで整理しています。

1. **現在地を明らかにする**：Azure Marketplace の無料ツール Nerdio Compass（パブリックプレビュー）で、現状を評価する。
2. **適切なパートナーを選ぶ**：組織に合った規模と形を選ぶ。
3. **変化に備える**：移行が終わる頃には新しい選択肢とデータが出てくるので、次の変化にも備える。

AVD Hybrid は一般提供となり、Nerdio Manager での vSphere 対応がパブリックプレビューに入ったことで、オンプレミスの仮想化基盤を残したまま、AVD と Nerdio Manager で管理を一本化できます。会場の最後では、Compass（Azure Marketplace へのリンク）と AVD Hybrid の詳細ページの QR コードが示され、Nerdio のブースは Moscone South の 5439 だと案内されました。
