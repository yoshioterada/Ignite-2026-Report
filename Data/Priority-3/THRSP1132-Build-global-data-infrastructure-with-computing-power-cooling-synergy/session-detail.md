# THRSP1132 Build global data infrastructure with computing‑power‑cooling synergy

## 1. はじめに

このセッションは、AI データセンター（発表では AIDC と略されます）を支える「ソフトウェアの裏側のハードウェア」、つまり **電源（power）と冷却（cooling）の設備** を扱う約 24 分の発表です。登壇者は、AI の GPU が高密度化したことで、データセンターの電力・冷却・建設のやり方そのものが変わりつつあると述べ、その対応として「電源チェーン」と「冷却チェーン」を GPU チップからデータセンター全体まで一体で設計する、という考え方を紹介します。

発表では、4 つの課題、6 つの技術トレンド、プレハブ（工場で事前に製造・試験する方式）による建設期間の短縮、そして電源側（UPS、800 V DC、ソリッドステートトランス、電力ユニット、太陽光・ガスタービン + 蓄電）と冷却側（液冷、CDU）の具体的な製品の方向性が順に語られます。

## 4. 発表者が伝えたいメッセージ

中心となる主張は、**AI の GPU 負荷に耐えるには、電源と冷却を別々に最適化するのではなく、チップからラック、データホール、建物全体まで続く 2 本のチェーンとして、計算とあわせて設計すべき**という点です。

その背景として、登壇者は次の事実を挙げています。

- GPU の世代が進み、1 つの GPU の計算能力は H100 から最新の Rubin で約 10 倍、キャビネット全体では 100 倍以上になる
- GPU の負荷変動は最大 180% に達し、従来の IT 負荷（最大でも 70〜80% 程度）とは大きく異なる
- 従来と同じ設備では GPU の学習負荷を支えられない

そのうえで、登壇者は 3 つの相乗効果（computing と power、computing と cooling、power と cooling）を狙い、無停電での電力供給、GPU の長期的な高効率運用、PUE の最小化、電力コストの低減、OPEX の最適化を目標に掲げています。

## 5. 発表内容の詳細

### 5.1 市場動向と GPU 進化による 4 つの課題

登壇者はまず、世界のデータセンター需要が急増しているとして、チャートを示しています。発話では、米国で今後数年に 30% を超える新規設置が起こり、2030 年には世界の設置の 50% 超が米国になる、と説明されています（音声認識の都合で、30% の意味は文面から確定できません）。AI の需要を支えるために、巨大なインフラが必要だという流れです。

需要を牽引するのは NVIDIA の GPU です。H100 から最新の Rubin に至る進化で、GPU 1 つあたりの計算能力は 10 倍に、キャビネット全体では 100 倍以上になると述べています。この高密度化が、次の 4 つの課題を生みます。

| 課題 | 登壇者の説明 |
| --- | --- |
| 1. 支援設備の占有スペース | データセンターでは IT サーバーが大きな面積を占めると思われがちだが、いまや GPU ラックよりもインフラ設備のほうが広い面積を占める |
| 2. 電力需要とコスト | 電力需要の増加、高効率化の要求、エネルギーコストの上昇により、供給とコストの圧力が高まっている。計算資源を借りたり買ったりするコストが高いのもこのため、と説明している |
| 3. 建設スピード | 米国では、環境や地域住民の反応の確認、資金調達、建設を経て、完成まで通常 2〜3 年かかる。顧客はそこまで待てない |
| 4. GPU 負荷の変動 | 従来の IT 負荷は 100% に届かないのが普通だったが、GPU の負荷変動は 180% 程度に達することがある。これをインフラが支える必要がある |

### 5.2 解決策: 2 つのフルチェーンと 6 つの技術トレンド

登壇者は、解決の枠組みを「2 つのフルチェーンのソリューション」と「6 つの技術トレンド」として紹介します。2 つのチェーンとは **電源チェーン** と **冷却チェーン** で、どちらもチップからラック、データホール、データセンターの建物全体へとつながります。AI データセンターで生成するすべてのトークンの安全を確保するには、電源と冷却を含む施設とインフラの安全が必要だ、という考え方です。これらの技術は、データセンター全体の PUE と、安定した計算能力のために適用されると述べています。

6 つのトレンドは次のとおりです。

1. **系統（grid）**: 系統接続による電力確保が難しくなっており、多くの州が、ガス設備や蓄電システムを作ってデータセンターの電力を支えようとしている（発話が不明瞭で、細部は確認できません）
2. **電源供給アーキテクチャの進化**: NVIDIA や OCP の動きとして、800 V DC のチェーンとソリッドステートトランスが登場し、アーキテクチャが段階的に変わる
3. **高性能な設備**: インフラの占有スペースが IT サーバーより大きくなっているため、省スペースと高効率を両立する設備が必要
4. **フル DC システム**: 現在は AC と DC の両方を使っており、800 V のデモシステムを数多く構築している。将来の新設データセンターは DC への移行を望むだろうと述べている。DC は AC とは安全性や短絡電流の扱いが大きく異なるため、フル DC を安全に運用すること自体が課題になる（短絡電流は発話で "source circuit power" と聞こえ、音声認識の都合で表記が確定できません）
5. **空冷と液冷のハイブリッド**: 現在は空冷が主流だが、高密度に対応するため液冷を導入する。空冷と液冷の混在、さらに純粋な液冷が将来の変化として挙げられている
6. **プレハブ納入**: 非常に重要で、次の項で述べるように納期を 50% 短縮できると説明している

### 5.3 建物と建設: モジュール化とプレハブ

登壇者は、AIDC の建物が低密度から高密度へ移りつつあり、レイアウトの最適化、機能ゾーンの計画、高性能設備の選定によって "5.0 IDC"（音声認識の都合で表記が確定できません）を実現したいと述べます。続けて、新設のギガワット級 AIDC の建物のイメージをスライドで示し、次のキーワードを強調しています。操作を伴うデモではなく、図の説明です。

- **モジュール化とプレハブ化（modular / prefabricating）**: 各階の計算ゾーン、冷却ゾーン、電源ゾーンがモジュール設計で、工場でプレハブ化できる。現場の建設作業が要らず、コンテナを現場に運ぶだけにできる
- **プラグアンドプレイ**: 工場で組み立てて試験まで済ませているので、現場では接続に時間をかけずに済む
- **speed to power**: データセンターに電気が来ていなくても、オフグリッドや再生可能エネルギー、蓄電システムを購入して設置することで、電力を確保できる

これらにより、最新の AIDC の建設方式では納期全体を **50%** 短縮できると説明しています。

### 5.4 電源から GPU までのトポロジーと 3 つの相乗効果

次に、150 kV の系統から低圧の AC、DC へと変換し、GPU チップに至るまでの電力経路を示すトポロジー図が紹介されます。各層にそれぞれ異なる製品と部品があり、層ごとに電源供給と保護をどう管理するかが問われます。登壇者は、GPU に安全な電力を届けるには、電源と冷却のインフラが各層で連携しなければならないと述べています。

AIDC は大量のトークンを生み出しますが、同時に電力損失、熱、AI 学習時のサージ電力も生みます。これらを抑えることがトークンを安全に得るために重要だ、という説明です。特に GPU 負荷の変動は最大 180% に達し、従来の 70〜80% 程度が最大だった曲線とは違います。従来と同じ設備では GPU 学習を支えられないため、インフラ側の課題になるとしています。

そこで、登壇者は計算・電源・冷却の多次元の相乗効果を提案します。

- 計算と電源
- 計算と冷却
- 電源と冷却

この 3 つは互いに関係しており、目標は無停電の供給、GPU の長期的な高効率運用、PUE の最小化、電力コストの低減、OPEX の最適化です。

**エネルギー供給側**: AIDC は、できるだけ施設の近くに電源を持つことを理想とします。太陽光、風力、蓄電システム、ガスタービンなどのグリーン電力を接続することで、電源の信頼性を高め、地域の系統の安定化にも役立つと説明しています。その背景として、Texas では系統側が 75 MW を超える AIDC の接続を望まない、という話が挙げられています。大規模なデータセンターの変動に対応するため、ローカルの電力設備による支えが必要だという主張です。

**電気システム側**: 電源モジュールやスキッドなどのプレハブ製品（発話では "skis" と聞こえ、音声認識の都合で表記が確定できません）は、AIDC を素早く納入するために欠かせないと述べています。電気機器については、省スペース、柔軟性、高効率、そして GPU の高頻度なピーク電力に耐える能力が求められます。

**冷却側**: 液冷がトレンドであり、データホールから熱を速やかに取り除いて、AI データセンターの熱需要を満たす必要があると述べています。

### 5.5 製品の 4 区分

製品は次の 4 つのシナリオに分けて紹介されます。

| 区分 | 説明 |
| --- | --- |
| power | 電源設備 |
| cooling | 冷却設備 |
| pod（発話では "port" と聞こえ、音声認識の都合で表記が確定できません） | NVIDIA の DSX pod が「計算の pod」であるのに対し、こちらは「インフラの pod」。IT ラック、熱システム、電源システム、監視システムを 1 つのコンテナに収めて施設に出荷できる、GPU のためのオールインワン環境 |
| ESS | エネルギー貯蔵システム。系統が不安定で電力が足りない現状では、系統側がデータセンター事業者に電力の面倒を見ることを求めており、蓄電が解決策になる |

### 5.6 電源ロードマップ

電源のロードマップとして、現在は AC システム向けの UPS が中心だが、将来は純粋な DC システム向けの **800 V HVDC** を使う、と説明されます。さらに 2027 年（発表では「来年から」）には **ソリッドステートトランス** が登場し、エネルギー損失を大きく減らせるとしています。

**UPS**: モジュール化が進んでおり、重要な点として登壇者は次の 2 つを挙げています。1 つは 100% 付近の負荷への対応です（発話が不明瞭で、詳細は確認できません）。もう 1 つは非常に高い密度で、この設計により UPS の設備スペースを **40% 以上** 節約できると述べています。リチウム電池は鉛蓄電池や従来のものよりスペースを大きく節約できるため重要だとしています。

**ソリッドステートトランス**: 新しい技術で、各社が今年発表している段階です。登壇者の会社の見通しでは、量産は 2027 年後半か 2028 年になります。中圧から 800 V へ直接変換するため、従来品に比べて効率損失が少なく、多段変換のシステムと、保守を速くするモジュール設計を備えると説明しています。

**800 V から GPU チップへ**: 800 V を GPU のチップへどう渡すかについて、登壇者は「break power unit」と呼ぶ製品が答えだと述べ、800 V から直接 50 V（聞こえた数値のまま）へ変換すると説明しています（製品名と数値は音声認識の都合で表記が確定できません）。この製品は JDM の製品になる可能性が高いとのことです（補足：JDM は共同設計製造を指す一般的な略語で、発話では展開されていません）。GPU やサーバーの設計が各社で大きく異なるためです。ラックの計算密度を上げるために、PSU を避けて電源チップをトレイの中に入れ、GPU トレイのスペースを確保する方向だと説明し、チップや IT サーバーの会社と次世代の GPU トレイを共同で検討したいと呼びかけています。

**PTU（power transit unit、音声認識の都合で表記が確定できません）**: データセンター用の建物がない場合のコンテナ型ソリューションです。電源システム用の 40 フィートのコンテナと、電力トランスとリチウム電池用の 20 フィートのコンテナで構成されると説明されています。現場での建設時間を **70%** 節約でき、標準は 2.5 MW です。米国の変圧器が通常 2.5 MW や 5 MW であることが理由と述べていますが、発話は不明瞭です。

**発電側**: 多くのデータセンターが系統接続を得られず困っているため、**太陽光、ガスタービン + 蓄電** の組み合わせが現時点で最良の解決策の 1 つだとしています（発話では "solar guest bind" と聞こえ、ガスタービンの意味かどうかは音声認識の都合で確定できません）。課題は、ガスタービンとの同期、サポート、電力を得る前のシミュレーションで、発電部分の標準的な解決策として 5 MW の標準ブロックを挙げています（用語は音声認識の都合で表記が確定できません）。

### 5.7 冷却: 液冷 pod と CDU

液冷は将来の AIDC のトレンドで、小規模なものから大規模なものまで液冷を導入できると述べています（発話が不明瞭で、エッジ AI への言及かどうかは確認できません）。

**液冷 pod**: ラックシステム、液冷システム、監視システム、電源システムを 1 つにまとめたもので、コンテナに入れてそのまま現場に出荷できます。現場の建設や調整が不要で、プラグアンドプレイで使えます。NVIDIA が持つ考え方と似ていると説明しています。

**CDU（cooling distribution unit）**: 液冷で非常に重要な部品です。登壇者によると、2 年前の 1 台は 300〜400 kW 程度でしたが、現在は 2 MW 以上になっています。GPU の進化が冷却分配の大型化を引っ張っているという説明です。CDU の 4 つの主要な特徴として、アーキテクチャの安全性、インテリジェントな管理、安全、保守の心配が要らないこと（worry-free O&M）が挙げられています（最初の語は音声認識の都合で表記が確定できません）。

次世代 CDU をハイパースケーラーと共同で開発することを歓迎しており、現在 Google など複数のハイパースケーラーと進めていると述べています。そのために、1,000 人を超える R&D 人員を投入していると説明しています。

## 9. まとめ

登壇者は、GPU の高密度化によって、データセンターの電源・冷却・建設の前提が変わっていると説明しました。対応として、電源と冷却の 2 つのチェーンを、チップから建物全体まで計算とあわせて設計し、プレハブ化したモジュールで納期を短縮することを提案しています。電源側では UPS から 800 V HVDC、ソリッドステートトランスへ、冷却側では液冷 pod と大容量 CDU へと進む方向性が示されました。目標は、より信頼性が高く、効率的で、コスト効率の良い AIDC インフラです。詳しい情報は、登壇者のブース（6040）で案内するとのことです。
