### 5.2 なぜ安全な基盤が必要か（Jenny）

**調査結果。** Jenny は、Deloitte の「2026 State of AI in the Enterprise」調査を引用しました。企業が従業員の AI 利用範囲を 1 年で 50% 拡大した（原文の言い回しでは「わずか 50%」）こと、技術基盤が AI 導入に対して十分に整っていると考える組織は 43% で、残りは中程度か低い水準だということです。AI の導入が広がる一方、基盤を強化する余地が残っており、パートナーが、お客様のインフラ、セキュリティ、ガバナンスのギャップを評価し、優先順位を付けて支援できる、という位置づけです。

**3 つの行動。** お客様が AI 対応の基盤づくりを始めるための 3 つの行動が示されました。

| 行動 | 使う製品 | 説明 |
| --- | --- | --- |
| データを AI 向けに準備する | Microsoft Purview | 機密データの分類、ラベル付け、保護 |
| AI 対応のワークスペースと安全なアクセス管理 | Microsoft Entra Conditional Access、Intune、Windows 365 | アクセス管理、デバイスとセキュリティポリシーの管理、従業員とエージェントに向けたクラウド PC の提供 |
| 保護と脅威対応を強化する | Microsoft Defender | 露出の特定、脅威の検知と対応 |

保護が組み込まれたプラットフォームは、規律を伴う「既定の状態」になり、インテリジェンスと信頼が一緒に働いて、生産性を落とさないという説明です。パートナーには、準備状況の評価、導入と定着、継続的なマネージドサービスという機会が生まれるとしています。

### 5.4 Ignite の新機能 2 件

Jenny は、Microsoft Ignite で Microsoft 365 の生産性プラットフォーム全体にまとまった革新として、Work IQ、Microsoft Purview によるデータ保護、エージェント向けの Windows 365、「Windows in Intune」を挙げました（音声認識の都合で、正確な表記は確定できません）。Microsoft は、AI を大規模に展開するためにお客様が必要とする基盤（Work IQ と生産性データから、保護、デバイス管理、ワークスペースまで）に投資を続けていると述べています。

1. **Microsoft Purview：機密情報を含むコンテンツを Copilot のグラウンディングから除外**。動画で見せたデータ損失防止ポリシーによる除外の考え方に続くもので、1 月にパブリックプレビューになる新機能です（年は発話では確認できません）。機密情報の種類として、財務データ、個人データ、健康記録、認証情報、組織固有のデータなどが挙げられています。保護がラベルだけでなく、コンテンツの機微性にも追従できるようになる、という点が重要だと説明しています。
2. **Direct Stream（Windows Cloud 向け）**。Windows Cloud は Windows 365 と Azure Virtual Desktop を指します。接続の信頼性、速度、通信のセキュリティ、セッション内の性能に関する長年の改善をまとめ、クラウド PC をローカル PC のように感じさせる機能です。ユーザーは数秒でクラウド PC に接続でき、厳しいネットワーク条件での接続の信頼性は、Windows 365 の登場時と比べて**約 300% 向上**していると述べています。

既存の AI 実践を持つパートナーは、安全な AI のアドバイザリー、導入と定着、エージェント型ソリューションの構築など 4 つの能力で既にサービスを構築しているはずで、今回の発表はそのそれぞれに投資する新しい機会になる、とも説明されました。たとえば Purview の新機能は、定着、構成、AI ガバナンスとセキュリティ戦略の策定に、パートナーの専門性が必要になる領域です。

Jenny は最後に、Purview、Microsoft 365、Work IQ、Windows 365 と Intune、Windows 365 for Agents が連携する体験として設計されており、これらが「AI 対応の基盤の構成要素」だと結びました。Microsoft が 50 年にわたって変化するお客様の要望に適応してきたことにも触れています。

### 5.6 パートナーの Win Formula と MCI

Win Formula は、顧客との取り組みの全段階をカバーする、資料とパートナー奨励金の全体像です。パイプラインの構築（狙うお客様の特定と需要の創出に使える資料群）から、ソリューション設計、案件の成約までを支援します。

ここでは、Microsoft 365 E3 と、Windows 365・Azure Virtual Desktop の奨励金を取り上げています。MCI は、一定の適格条件を満たすパートナー向けのプログラムで、販売前と販売後に対応する 3 つの取り組みの形があり、組み合わせると**1 案件あたり最大 77,000 ドル**の獲得可能性があるとのことです。

| 取り組み | 時期 | 内容 | 顧客の条件 | 上限 | パートナーの条件 |
| --- | --- | --- | --- | --- | --- |
| Envisioning and PoC（構想と PoC） | 販売前 | 1 対 1 の販売前支援。お客様の意向を高め、案件を前に進める。コンプライアンスと技術の評価、ソリューション設計、パイロットにつながる PoC、ビジネスケース作成などが対象 | 必要ライセンス 300 席から。エンタープライズから SMB まで対応 | 顧客規模に応じて最大 20,000 ドル | モダンワークまたはセキュリティの 専門性認定（Specialization）が必要。成果目標の達成が求められる |
| CSP Deployment Accelerator | 販売後 | CSP のお客様の導入と定着のコストを補う 1 対 1 の取り組み | CSP サブスクリプションで 50 席以上の増分購入 | 顧客規模に応じて最大 32,000 ドル | 同上の 専門性認定 と成果しきい値 |
| Conversion Bonus（FY27 の新制度） | 販売後 | 対象となる戦略的プラットフォームから、Microsoft の生産性・セキュリティソリューションへ移行させたことへの報奨。Deployment Accelerator を提供したうえで、お客様を推薦する形で上乗せされる | 発話では確認できません | 最大 25,000 ドル | 発話では確認できません |
| Azure Virtual Desktop の資金 | VDI 移行 | 仮想デスクトップ基盤の移行を支援 | 計画する Azure 消費のプロジェクト規模（5 段階） | 最大 40,000 ドル | Azure Virtual Desktop の 専門性認定。SMB 向けにはインフラソリューションの指定を持つパートナーの別の枠。成果目標の達成が求められる |

Cindy は、Envisioning and PoC について、すでに資格を満たすサービスを提供しているパートナーも多いはずだと述べています。Deployment Accelerator は、販売前の段階から、将来の奨励金の支払いを作業範囲に織り込んで使うよう勧めました。

### 5.9 CSP の更新期と 3 つの優先事項（Marcelo）

後半（1 月から 6 月）は、更新対象の席の大半が集まる、1 年で最も重要な時期です。**CSP 顧客の 60%** が、この期間に更新を迎えます。新規顧客の獲得は既存顧客の維持より最大 7 倍高くつくため、更新は最も安価な成長の一つだとしています。更新には 3 か月以上かかることもあるので、いまのうちに案件を洗い出して準備するよう呼びかけました。

優先事項は 3 つです。

1. **更新を確実に取る**。更新の時点で、お客様が継続するか、離反するかが決まります。ASPX と Cloud Ascent（どちらも Win Formula のツールとして語られています）で、更新予定とお客様の状況を把握して準備します。
2. **プレミアム（ME3）へのアップセル**。更新のときに行うのが望ましいが、常時行う動きでもあります。ASPX と Cloud Ascent でアップセルの可能性が高いお客様を見つけ、campaign in a box（すぐ使えるキャンペーン一式）で働きかけ、Envisioning and PoC に推薦します。
3. **セキュリティで拡大する**。これも常時行う動きです。ME3 の基盤ができたら、ME5、さらに ME7 の価値を提案していきます。

更新で顧客を維持し、ME3 へのアップセルで顧客の価値とサービス収益の機会を高め、セキュリティで関係を深めてサービス収益の機会をさらに広げる、というのが成長の道筋だと整理しています。

2. 適切な MCI または ESA（略語は発話のまま。音声認識の都合で表記が確定できません）の資金を、Envisioning や PoC の開始に合わせる

- 頼む前に与える。営業担当に成果が出れば、パートナーシップは続く

### 5.11 3 つの要点と行動の呼びかけ（Cindy）

3 つの要点は、(1) AI 対応の生産性の価値と市場の勢いがかつてなく大きい、(2) パートナーの機会は広がり、更新の波が近づいているので、いま計画と優先順位付けをして顧客を維持・アップセルし離反を抑える、(3) 紹介した市場投入（Go-to-Market）の投資（MCI の取り組みと CSP プロモーション）を活用して収益性を高める、です。

行動の呼びかけは次の 4 つです。

1. **スキルを高める**：営業と技術のチームをスキルアップする。Partner hub のスキル習得用リソースに、安全な基盤向けの学習パスがある
2. **専門性認定を取得する**：AI 対応の生産性のスキルを示す。Microsoft の営業現場は、共同販売の相手を選ぶときに 専門性認定を持つパートナーを見る
3. **実践を築く**：オファーの開発、独自資産（IP）の作成、デリバリーの変革を助ける指針と資料がある
4. **市場投入**：紹介した資料と投資を活用する

## 6. デモ・手順

画面操作のライブデモは行われていません。Jenny が事前に録画された動画を 1 本再生し、同じ従業員が同じ作業（提案書づくり）をする 2 つの場面を左右で比較しています。画面の細部は音声からは確認できません。語られた範囲は次のとおりです。

1. **左側：データ保護が設定されていない Copilot**。従業員が Copilot を使って提案書を作り、続けて文書を追加する。この文書は、経営幹部だけでなく、誤ってチーム全体に共有されていた。ユーザーはこの文書へのアクセス権を持っているため、Copilot は回答を修正してその情報を含めた。作業は速く進んだが、従業員が見るべきでない機微なデータが含まれ、データ保護のギャップが明らかになった
2. **右側：データ保護が設定された Copilot**。同じ従業員が同じ作業をするが、データ保護のギャップが解消された信頼できる基盤の上で行う。過剰共有のリスクが軽減されており、このシナリオでは回答が変わる。組織のポリシーが同じ文書をチーム全体に共有することを許していても、この従業員にはアクセス権がなく、機密ラベルが設定されているため、Copilot は機微な情報を含めずに、役に立つ回答を返す
3. **結果を分けた 3 つの要素**：
   - データに機密ラベルが付き、経営陣のような特定のグループにしか共有されないようポリシーで制限されている。その人がアクセスできる情報だけが表示される
   - ID とデバイスのポリシーが、本人が認証され、適切なアクセス権があり、デバイスが準拠していることを確認する
   - セキュリティの設定とポリシーが、作業を中断せずにバックグラウンドで動作し、必要なときに対処に備える

Jenny は、従業員は適切な機密ラベルがあるので安心して情報を使い続けられ、IT は管理を保てると説明し、これを信頼できる基盤の力だとしています。

## 7. 注意点・発表者の気付き

- MCI の 3 つの取り組みと AVD 資金では、パートナーに 専門性認定（モダンワークまたはセキュリティ。AVD は専用の 専門性認定）が求められ、成果目標の達成も求められます
- Deployment Accelerator は、販売前の段階から将来の支払いを見込んで作業範囲に織り込むよう勧められています
- Conversion Bonus は Deployment Accelerator を提供した後で推薦する形で、上乗せになります
- 試算の新規顧客シナリオは最も起こりやすいケースではないかもしれない、と Marcelo が断っています。サービス収益は試算に含まれていません
- Purview の機密情報による Copilot のグラウンディング除外は、1 月のパブリックプレビューの予定（年は発話では確認できません）で、提供済みの機能ではありません
- お客様は AI のスイッチを入れるだけでは使えず、セキュリティ、ガバナンス、データ基盤の作業が先に要ります
- 共同販売では、アカウントチームに依頼ではなく計画を持っていき、お客様の前で驚かせないことが助言されています

## 8. 利用者にとっての利点

- 機密ラベル、ID・デバイスのポリシー、バックグラウンドのセキュリティ設定により、Copilot が役に立つ回答を返しつつ、本人が見るべきでない機微な情報を含めない。従業員は安心して使え、IT は管理を保てる
- Purview の新機能（1 月にパブリックプレビュー予定）で、機密情報の種類（財務、個人、健康記録、認証情報、組織固有のデータ）に応じて、グラウンディングから除外できる
- Direct Stream で、クラウド PC に数秒で接続でき、厳しいネットワーク条件での接続の信頼性は Windows 365 登場時と比べて約 300% 向上している
- 更新期のプロモーションと価格保護：ME3 の 3 年契約で価格変動からの保護とコストの予測可能性が得られる
- Invoke の事例：エネルギー企業は 11,000 のメールボックスを Exchange Online に移行し、グローバルなエンジニアリング企業は 17,000 台のデバイスを Intune に移行した。いずれも ME3（または E5）を起点に、Copilot やエージェント活用へ進んでいる

## 9. まとめ

AI の導入を求めるお客様が増えるほど、データ保護、ID、デバイス、セキュリティの基盤が欠かせなくなり、パートナーには、評価、導入、定着、マネージドサービスの機会が生まれます。Forrester の調査では、Secure AI productivity で 1 ユーザーあたり月額約 44 ドル、Windows Cloud で 27 ドルのサービス収益が見込まれ、マネージドサービスが差別化の鍵とされました。
